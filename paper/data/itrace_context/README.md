# ITrace frozen-checkpoint context ablation source data

These files are generated by
`paper/figures/make_itrace_context_ablation_figure.py` from
`output/itrace_zero_shot_context/`. The main cohort contains 244 PDB complexes
after excluding the exact training-set PDB overlap `3KXF`.

- `panel_a_per_complex_spearman.csv`: one row per complex for the paired
  full-complex versus isolated-chain Spearman scatter.
- `panel_b_metric_advantages.csv`: seven dimensionless paired effects,
  complex-bootstrap 95% confidence intervals, Wilcoxon p-values and
  Benjamini-Hochberg q-values.
- `panel_c_role_spearman.csv`: chain-role-stratified Spearman effects.
- `panel_d_role_rmsf_scale.csv`: all 3,660
  complex--chain-role--input-condition values used by the RMSF scale panel.
- `panel_d_role_rmsf_scale_summary.csv`: plotted macro means and
  complex-bootstrap confidence intervals.
- `per_complex_metrics_external_clean.csv` and
  `per_chain_metrics_external_clean.csv`: complete metric tables for the
  external-clean cohort.

No rows are sampled for visualization. The independent statistical unit is
the PDB complex; intervals use 2,000 complex-level bootstrap resamples.
