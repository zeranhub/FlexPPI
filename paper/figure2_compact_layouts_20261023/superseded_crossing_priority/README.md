# 图2当前选定构图：a–c，按任务设置PR纵轴

当前主文件为fig2_compact_merged.pdf，另有同名可编辑SVG、450 dpi PNG及完整预览fig2_compact_merged_preview.png。画布183 × 150 mm，全部可见字号至少9 pt；正式v61 Word未覆盖。

a与b沿用上一轮：RMSF/Hχ双坐标叠加、实线趋势、无白底指标和一根双色Mass标尺；b宽71 mm，按三个任务分别显示四方法AP分布，每组从左到右Full、Intra、Static、AA。

c仍是一个PR组合面板，没有冗余总标题，共用Recall说明；三张图各自显示Precision和实际刻度，纵轴分别设置：

| 任务 | 原始Precision范围 | 占0–1显示范围的比例 |
|---|---|---|
| RMSF | 0–0.5；0.5–1 | 25%；75% |
| 总体Hχ | 0–0.5；0.5–0.9；0.9–1 | 10%；35%；55% |
| 同类型Hχ | 0–0.45；0.45–0.75；0.75–1 | 12%；78%；10% |

三轴均为连续、严格递增的分段线性坐标，覆盖完整0–1，没有断轴或省略AA低值；顶部均在变换后的空间留2.5%余量。PR数据区高40 mm，宽42 mm，列间留足位置容纳各自刻度和轴名。图内比较方法时应读本图刻度，三个任务的画布高度不再表示相同Precision增量。

每次绘制均逐值核对36,756个AP点、1,224个PR顶点；15个源档案、3,063条记录、12个冻结AP均值和各任务阳性率基线均不变。AP来自原始Precision阈值曲线，不从变换后的视觉面积重算。运行python plot.py重建、python verify.py核验。
