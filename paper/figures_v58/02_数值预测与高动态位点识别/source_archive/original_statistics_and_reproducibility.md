# Figure 2 statistics and reproducibility

This revision consumes the existing five-fold out-of-fold predictions used in v44. The four method scores, valid masks, record identities, folds and MD references are unchanged. Full is the complete structure model; Intra is the separately trained intrachain model; Static is static-feature regression; AA is the training-fold amino-acid-type mean baseline. No fitting, new inference, recalibration, MD simulation or test-set threshold tuning is performed.

The statistical unit is one input record, not one residue. The same 3,063 records are retained for all methods and tasks. RMSF uses 961,321 positions and Hchi uses 824,988 positions. Source counts are ATLAS 1,929, DynaRepo 890 and ITrace 244. The type-constrained task uses all 42,108 eligible record/type combinations. Every input identity, mask and reference is verified by `../analysis/addition_audit.json` and the full SHA-256 manifest `../analysis/inputs_sha256.json`.

Panels a/b contain all original Full/reference observations in `source_archive/prediction_reference_<target>.npz`; there is no subsampling. Each position has weight 1 / (3,063 x valid-position count of its record), so each record contributes equal total probability mass. The complete 90 x 90 cell-mass arrays sum to one for each target. Zero cells are white. The neutral grey density key uses a shared logarithmic mass normalization. Density is Full only; the four overlaid colored curves are descriptive conditional means of unchanged predictions, not recalibrated predictions. Both axes show the same complete range with equal physical scaling: RMSF spans 0 to 33.1866645813 Angstrom using symlog with threshold 1 Angstrom; Hchi spans 0 to 4.05713891983 nats using a linear scale. The ideal diagonal is not fitted. MAE and Spearman annotations are record means.

All four curves use the same 20 reference-bin boundaries per target and the same original observations. Weights are inverse record-valid-position count; the additional common 1 / 3,063 factor cancels within conditional means. Full's curve and its 95% interval reproduce v44 within absolute tolerance 2e-12. Empty RMSF bin zero remains as an undefined row for each method and is not bridged or filled. Full's interval uses the first 1,000 of the same original 10,000 source-stratified record bootstrap draws, seed 20261018. Curves and supports are in `source_archive/four_method_binned_trend.csv`, 160 rows including four empty-bin rows. Intra/Static/AA have no uncertainty band.

Panels c/d define a positive position as MD reference greater than or equal to its own record/target 90th percentile (NumPy linear quantile), retaining all reference ties. Original continuous model scores rank positions; score ties are selected as a complete threshold group. No record has a one-class result. At recall 0, .01, ..., 1, precision is sampled at the first original threshold reaching that recall and averaged equally over records. The no-selection point is (0, 1). The genuine all-selected endpoint is appended after the 101-point grid at recall 1, because the first threshold reaching recall 1 may still omit negatives. Full-selection mean precision is .1025790965 for RMSF and .1029139433 for Hchi. The horizontal grey lines show these actual positive fractions, not a rounded 10% threshold.

Panel e applies that ranking evaluation within each record and amino-acid type. Eligibility requires at least four valid positions and both classes at the fixed within-type MD q90 threshold; 10,493 too-small and 2,533 one-class combinations are undefined, exactly as in v44, and all 42,108 eligible combinations remain. A metric or precision-grid coordinate is first averaged over eligible types within each record and then equally over 3,063 records. This prevents records with more eligible types from receiving extra weight. The mean prevalence and genuine full-selection precision are .1463302731, rather than .10, because small groups and reference ties are retained. All 101 sampled precision points and the appended original final endpoint are plotted for every method. Raw complete curves, type-to-record mapping, record macro grids and exact type metrics are retained in `../analysis` and copied into the self-contained source archive.

The displayed AP values in c/e and the f matrix are means of exact noninterpolated AP: sum of each original threshold's recall increment times that threshold's precision, with ties kept together. AP is never calculated by integrating the displayed macro curve. AUROC values remain the corresponding exact record means from v44 and are reported in the manuscript; no redundant AUROC panel is added. No new hypothesis tests, significance annotations or multiplicity correction are introduced. PR confidence-grid data are retained but no overlapping four-method bands are drawn. Existing AP/AUROC 95% intervals use the original 10,000 source-stratified record bootstrap draws, seed 20261018.

Panel f uses 36 cells (four methods x three tasks x three sources) with a common 0..1 sequential scale and three-decimal numeric labels. Each cell is the mean exact record AP within that source. Within-type AP has already been equally averaged over eligible types in each record before source aggregation. Source means weighted by their record counts reproduce the overall AP. The source matrix is a descriptive view of the same five-fold predictions; it does not represent leave-source-out training. The tasks have different positive definitions and positive fractions, so absolute AP between tasks is not used to infer task difficulty. Its complete source is `source_archive/source_ap_matrix.csv`, including `full_minus_method_ap`, all nine sample sizes and all 36 exact values.
