# 图2期刊原图调研与构图判断

2026-10-23。正式论文仍为v61；先前的独立性能点图候选未采用。本次核看正式论文原图，目的在于确定适合FlexPPI的数据表达与构图，不以期刊名称代替设计判断，也没有生成新论文版本。

先前候选的问题是把不同证据压成了相似的横向指标行：预测与MD的点云、PR曲线形状消失，主体变成平均数、区间与小号文字；下层配对差散点又因全范围与窄分布的组合失去视觉分量。方法之间虽然分开了，整张图却更像统计表。v61的真实密度云和完整PR是值得保留的部分。以下对构图好坏的判断与对FlexPPI的适用建议，均为这次调研后的设计推断，不是所引论文对FlexPPI的评价。

## 最值得参考的四组原图

**RMSF-net，Nature Communications 15, 5538（2024），Figure 2c–g。** [正式原文](https://www.nature.com/articles/s41467-024-49858-x)及[Figure 2](https://www.nature.com/articles/s41467-024-49858-x/figures/2)。已视觉检查出版社原图，并交叉查看正式PDF第5页。c/e/g让同一蛋白在两种模型下的相关性分别成为横纵坐标，配相等参考线；d/f显示跨蛋白的性能分布。最有用的是把“Full预测是否接近MD”和“Full是否在多数输入上优于对照”分成不同的图形角色。对于我们，后一问题适合逐记录配对比较，不必继续在同一密度云上挤四条条件均值曲线。它的流程图、多套配色和密集分桶条图不应照搬；原g还限定了一个相关性子集，我们不照搬该筛选。

**MISATO，Nature Computational Science 4, 367–378（2024），Figure 5。** [正式原文](https://www.nature.com/articles/s43588-024-00627-2)及[Figure 5](https://www.nature.com/articles/s43588-024-00627-2/figures/5)。已视觉检查正式PDF第6页。左侧保留预测—真值散点，右上给跨结构的相关性和top-100表现分布，右下用同一结构的参考与预测回应实际位置。值得借的是“总体关系—跨结构稳定性—空间对应”的互补，而不是其具体指标。我们图3已有结构案例，因此不需要把同类结构例子再塞进图2。这里的分布描述结构之间的差异，不能标成均值置信区间。

**STARLING，Nature 652, 240–250（2026），Figure 2。** [正式原文](https://www.nature.com/articles/s41586-026-10141-2)及[Figure 2](https://www.nature.com/articles/s41586-026-10141-2/figures/2)。已视觉检查出版社Figure 2和3原图。Figure 2上方保留预测与模拟参考的密度散点，中间用浅色柱与对照曲线展示分布，底部把位点对误差和相应分布配起来。该图表明点云、曲线与热图可以并存，只要各自回答不同问题。我们应保留a/b的数值关系，将方法比较交给独立的配对图；不照搬它的大量例子、示意插图和面板数量，也不借用其构象集合分布冒充我们两个标量读数的输出。

**Experiment-guided AlphaFold3，Nature Biotechnology（2026），Figure 3。** [正式原文](https://www.nature.com/articles/s41587-026-03166-5)及[Figure 3](https://www.nature.com/articles/s41587-026-03166-5/figures/3)。已视觉检查出版社Figure 2和3原图。Figure 3将原始指标分布与相对参考的改善分布邻接，参考线明确解释改善的方向。值得借的是绝对性能与改善证据之间的对应关系。我们的MAE/AP应先显示真实水平，必要时再显示同一记录的差值；不能整张改成小提琴图，也不能把RMSF与Hχ不同单位的误差混在同一尺度上。

## 另外核看的正式论文

**ITsFlexible，Nature Machine Intelligence 7, 1755–1767（2025），Figure 2、3。** [原文](https://www.nature.com/articles/s42256-025-01131-6)及[Figure 3](https://www.nature.com/articles/s42256-025-01131-6/figures/3)。已查看正式PDF第4、5页。跨测试集重复同一套分类评价语法、下方加结构例子的组织可参考；其大量灰色条图与拥挤坐标并不适合直接作为本次美观模板。

**Graphinity，Nature Computational Science 5, 635–647（2025），Figure 2。** [原文](https://www.nature.com/articles/s43588-025-00823-8)及[Figure 2](https://www.nature.com/articles/s43588-025-00823-8/figures/2)。已查看正式PDF第4页。预测—真值散点、严格数据切分下的性能折线、真值与预测分布各自提供不同信息。值得借其保留预测范围收缩等边界现象，不宜借来把我们的图2扩成更多无关评价。

**EVE，Nature 599, 91–95（2021），Figure 2。** [原文](https://www.nature.com/articles/s41586-021-04043-8)及[Figure 2](https://www.nature.com/articles/s41586-021-04043-8/figures/2)。已查看正式排版PDF第2页及出版社图注。三个子图分别用AUC分布、准确性与不确定阈值的关系、两个独立评价维度的散点承担不同角色。可以借“一个问题一种合适图形”的思路；我们没有对应的不确定性筛选实验，因此不照搬它的阈值曲线。

## 对图2的具体方向

更合适的方向是保留原图的真实数据形态，并调整比较任务。两张Full预测—MD参考密度图继续承担数值准确性；四方法的条件均值线不再独自承担“谁总体更好”的解释。接近方法之间的比较改用同一记录的成对性能散点或明确的性能分布，让点相对相等参考线的位置反映胜负及幅度；不会把每一对方法都展开成九宫格。完整PR继续承担高动态位点识别，尤其给同类型Hχ足够面积，而总体Hχ接近的曲线仍保持接近。来源AP矩阵是稳健性证据，版面不足时可保留为配套图，不能为了版面静默删掉对应数据。

具体实现仍需在同一统计单位上检查图形是否适配。逐记录散点一颗点对应一条记录，不把残基当独立蛋白；AP沿用完整阈值结果，不对显示曲线重新积分；差值为同一记录先做差，保留负值、并列与全部记录。分布宽度表示记录间差异，均值95%区间表示均值估计的不确定性，两者不混用。Full与Intra在总体Hχ上很接近是现有数据的事实，不能把“顶刊风格”解释成应将它们刻意拉开。

本次只形成原图参照与构图方向，未改动v61。没有把AlphaFlow、Flexpert、BackFlip等会议论文称为Nature/Science正式论文；BioEmu虽核到Science正式发表，未成功核看原图，因此不纳入本次视觉比较。
