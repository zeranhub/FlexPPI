# Figure 2 v44: evaluation protocol fixed before metric computation

Protocol date: 2026-10-18 (Asia/Shanghai). This is a new evaluation of existing out-of-fold predictions. It performs no training, model inference, MD simulation or calibration.

1. Check all 3,063 full-model and intrachain NPZ records against the original per-residue truth table and the static training schema. For every record, compare sample/source/fold, residue index, amino acid, chain, author residue ID, reference targets and valid masks. Verify static/AA ordering by training schema, target/valid arrays and reproduced original per-record errors. Finite common positions across all four methods form the identical support; report every exclusion and every undefined metric.
2. For each target and record separately, define a positive as MD reference >= its 90th percentile, computed by NumPy linear quantile. Keep all threshold ties positive. Rank continuous unaltered predictions; equal scores move together as one threshold group. A record with only one resulting class has undefined AP, AUROC and PR and remains in coverage. No selection uses observed predictive performance. Scores are original OOF predictions, without evaluation-set type-mean calibration.
3. Average precision (AP) is the sum of each recall increase times precision at that threshold, without trapezoidal integration. AUROC is the trapezoidal ROC area with tied score groups, equivalent to a half-credit tie pair comparison. Save every record's original PR/ROC threshold points, including the no-selection endpoint. Macro AP and AUROC give equal weight to eligible records.
4. Macro PR displays record-equal mean precision at recall grid 0, .01, ..., 1. For each record and r > 0, use precision at the first complete score-tie group whose recall is >= r; for r = 0 use the precision=1 no-selection endpoint. This is a right-endpoint step evaluation of the original threshold curve. No precision envelope, smoothing, best-threshold selection or tie-breaking is applied. The macro curve is descriptive; its plotted-grid area is not called mean AP. The no-skill baseline is record-equal positive prevalence, which may exceed 10% because of MD ties.
5. Use source-stratified record bootstrap, 10,000 draws, seed 20261018, for macro AP/AUROC confidence intervals. Preserve original number of records in each source stratum, sample records with replacement, and use the same draws for methods. Curve and binned-trend intervals use the first 1,000 draws. Records, not families or individual residues, are the bootstrap units.
6. The density panels use every Full/reference common-valid point with weight 1/(number of records times valid positions in that record). They retain the entire observed reference and prediction range. RMSF bin edges are equally spaced after a symlog transformation with linear threshold 1 Angstrom; Hchi uses linear edges. Cell values are total weighted probability mass, not pooled point count. Binned trend is a descriptive weighted conditional mean of original model predictions within MD-reference bins; it never transforms or recalibrates a prediction. Save all original points and bin data. Report original-unit record-macro MAE and record-mean Spearman, checking against original per-record exports.
7. Auxiliary Hchi within-type ranking repeats the same q90/tie rules separately within each record and amino-acid type having >=4 common-valid positions. Every type with fewer positions or only one class is explicitly retained in eligibility accounting. First average AP/AUROC across eligible types within a record, then average records equally. AA-only is constant within a record/type, so its AP must equal that subset's prevalence and AUROC must equal 0.5. This is an auxiliary evaluation, not a new model.

Display clarification after the first plot (no metric or interpolation change): also show the separately saved full-selection operating endpoint at recall=1 and record-macro positive prevalence. This endpoint is the final point of every original threshold curve and is appended after the 101-point first-reach display grid, so any remaining descent at full recall is shown as a vertical segment. It is not used to recompute AP or AUROC. Auxiliary coverage explicitly includes absent amino-acid types with zero valid positions among the 18 chi-bearing types.
