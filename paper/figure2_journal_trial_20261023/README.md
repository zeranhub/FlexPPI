A/B使用的配对图横轴是Static AP、纵轴是Full AP；一个点是一条记录，不是一个残基，也不将记录声称为独立蛋白样本。相等线以上为Full更高。A完整显示RMSF及同类型Hχ各3,063条记录，B只将同类型任务配对图放在主图中。统计分别为RMSF 2,258高/15平/790低、同类型Hχ 2,487高/16平/560低；其余输入方法在每版完整PR中均保留。没有用筛点、放大窗或断轴制造优势。

C每任务每方法均用3,063个原始AP，三个任务四方法总计36,756个记录值；小提琴的轮廓是全部记录分布的核密度外形，带宽0.20，严格限于各组实际最小与最大值之间。每个原始AP点都显示，仅在横向作确定性错开，不改变纵轴数值；内粗条为第25—75百分位，白短划为中位数。这些范围表示记录间的差异，不是均值置信区间，也没有增加显著性检验。

三个任务的全部方法PR均保留101个显示网格点及真实全部入选终点，共1,224个顶点；AP沿用原始完整阈值曲线计算后的记录均值，不从显示曲线重新积分。总体Hχ Full/Intra真实接近的部分保持接近，同类型Hχ沿用原有效性定义与记录内类型等权平均。
