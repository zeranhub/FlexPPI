# Figure 2 relayout: statistics and reproducibility

The figure uses the frozen original data. No model is retrained, no data point is dropped, and no model metric is recalculated by this relayout script. Main-panel a and b are reused directly from the original native PDF at the same 183 mm physical width. The three interface-stratified bar charts are reused directly from their original native PDF with the same 183/150 scaling used by the manuscript composite; only panel letter d becomes f.

Main c: within-type Hchi retrieval, 3,063 records. Four controls (Full, Intra, Static, AA) retain all 102 original PR vertices each, including the all-selected endpoint. The original continuous piecewise-linear precision-axis transformation is retained with knots [0,0.45,0.75,1], display heights [0,0.12,0.90,1], ticks [0,0.6,1]. AP is the frozen equal-record mean (Full 0.623, Intra 0.609, Static 0.555, AA 0.146); curves are not integrated to replace AP. Each eligible record/type is evaluated before aggregation as documented by the original calculation. No confidence band is added.

Main d/e: seven methods, identical 615 DynaRepo protein complexes, 261 families and 260,340 residues. Positives are residues at or above each record's true RMSF 90th percentile; tied values are retained. Curves are equal-record means on the frozen 1,001-point common recall/FPR grid, without smoothing. PR retains the first threshold reaching recall one and a separate all-selected endpoint; ROC retains empirical vertical-start segments and the corrected interpolation that respects ordered duplicate FPR vertices. The shared legend table reports the independently averaged exact per-record AP and AUROC, not the area of the display curve. No curve confidence band is shown. Frozen scalar confidence intervals in the source summary use 2,000 family-cluster bootstrap draws, seed 20261024, percentile 95% intervals.

Main f: all original seven-method grouped bars for Spearman rho, high-RMSF AP and standardized MAE remain. Strata contain 414 records/196 families (one interface), 144/58 (two to three), 57/34 (at least four). Means are equal-record averages. Error bars are original 95% family-cluster bootstrap percentile intervals from 2,000 draws, seed 20261024. Family memberships can span strata. No new hypothesis test or multiplicity adjustment is introduced.

Supplement S3a/b: original RMSF and overall Hchi internal-control PR panels. Each panel preserves all 408 vertices, all four methods and frozen AP. Precision axes retain the original task-specific continuous piecewise-linear transformations: RMSF knots [0,0.5,1] to display heights [0,0.25,1]; overall Hchi knots [0,0.5,0.9,1] to [0,0.10,0.45,1]. These unequal axis spacings must be disclosed in the caption; AP remains the original raw-threshold calculation.
