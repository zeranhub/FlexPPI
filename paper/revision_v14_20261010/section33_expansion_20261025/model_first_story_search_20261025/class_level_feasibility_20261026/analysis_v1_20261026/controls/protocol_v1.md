# 冻结家族留出对照协议 v1（2026-10-26）

本分支只读原始结构、标签、模型和论文；所有新增结果仅写入 controls 目录。正式成员由 `short_peptide_5to40_candidates.csv` 中 `two_chain_unambiguous=True` 冻结，56条记录、54个PDB、46个family连通分量。成员不根据结果剔除。按肽侧与受体侧分别评价，接触定义沿用伙伴Cα严格8 Å阈值。主要汇总先记录内平均，再同PDB记录平均，最终PDB等权；稳健性用family等权及family成簇重采样，不把残基当独立重复。

已有 SASA 和 Static47 特征可直接复用；它们从单次冻结输入结构计算，无MD或预测值作为特征。然而已有三套非神经基线使用原始五折，不能拿来和本次family OOF比较。本分支按 `family_folds/record_family_folds.csv` 的冻结fold重新拟合，训练仍用全部3063条记录中留出折以外的原始有效标签，不将队列限制为56候选，不进行神经模型或MD重跑。每个留出折内所有family均不进入训练，逐折审计训练/测试family交集为零。

先完成 Static47+SASA，然后完成 AA+SASA+contacts。前者有中心及邻近氨基酸、链长、链端、主链φ/ψ及键角、链内/跨链Cα接触和整残基/侧链暴露及遮蔽；主链角度已提供局部二级结构构象信息，不把未计算的DSSP称作现成特征。后者只有中心氨基酸、六种面积与链内/跨链接触，用于检验简单埋藏环境能解释多少。两套基线均额外读取完整侧链重原子，因此比FlexPPI主链输入更丰富，是解释性强基线，不是等输入预算消融。

固定采用既有预算：Histogram Gradient Boosting，平方误差损失，120轮，learning_rate=0.07，max_leaf_nodes=31，min_samples_leaf=50，l2_regularization=1，max_bins=63，seed=7，禁用early stopping；不看本队列成绩选择参数。每套5折×RMSF/Hχ两个目标，共10个拟合。连续顺序拟合、最多2线程；全体有效训练残基均使用，无行数抽样上限。每次拟合的权重继承原基线：来源等权、来源内生物系统等权、系统内记录等权、记录内有效残基等权。AA均值对照由同一训练折/权重额外计算，不调参。完整表53列float32输入约204 MB，实际峰值还包括训练副本、分箱和模型工作区；脚本记录系统进程峰值内存和各拟合耗时、行数。

先用冻结原始标签评价；统一MD标签由另一分支独立复算，本分支将冻结预测与统一标签对齐进行稳健性评价，不因新目标重新选参。主结论需同时报告Full对Intra及Full对两套家族留出强基线的差异；若增益被结构基线解释，照实报告。按AA分层及主链参考值接近的配对分析只用于区分侧链信息，不能声称观测了动力学因果或生化机制。

预定分析：两角色×RMSF/Hχ，all/接触/非接触/完整侧链；每PDB及每family的MAE与Spearman；Full对基线的配对MAE差、改善计数与family成簇区间；Hχ在相同AA、同角色、同记录内且MD主链RMSF差≤0.25 Å的残基对上的差异预测误差（记录内先平均，再PDB/family汇总）。每条记录不满足某子集/配对时保留零覆盖标记，不以失败为由删去体系。
