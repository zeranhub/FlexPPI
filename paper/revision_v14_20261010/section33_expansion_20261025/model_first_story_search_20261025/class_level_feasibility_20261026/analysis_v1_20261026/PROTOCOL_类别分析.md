# 类别分析固定口径，2026-10-26

本分析由单例探索和54PDB初核后提出，属于探索性扩展，不作预注册宣称。成员纳入不依据模型成绩。宽队列固定为shared/candidates_frozen56.csv的56记录/54PDB，结构标准为两条蛋白链、5—40残基短链、另一链至少70残基、身份不同、双方存在跨链Cα8 Å接触且RMSF与Hχ均有有效位置。54PDB共46个数据划分连通组；连通组不自动等同于生物学家族。

生物注释依据已缓存的官方RCSB结构/聚合物元数据和原始论文标题摘要，分类成识别基序/功能片段、天然短肽/激素、抑制/底物肽、设计/药物肽、折叠小蛋白/小结构域、装配或任意截片以及不明确。主核心为证据明确的功能识别片段、天然短肽或相关抑制/底物肽；折叠小蛋白、独立小结构域、合成肽与不明确成员留在宽队列和敏感性分析中，各自单列，不以成绩删去。不能将整个短链类别称为天然无序蛋白。

预测使用已冻结的家族整组留出Full与Intra。Full/Intra为同一结合态输入的分别训练模型，不是删除伙伴后的同一模型扰动，也不是游离/结合状态对照。额外强基线按相同family折训练，采用固定既有预算的梯度提升回归：Static47+SASA、AA+SASA+contact以及氨基酸均值。全部可用训练残基纳入，不使用测试标签调参；原五折静态基线不与family OOF直接比较。强基线可使用全原子SASA，信息比神经模型主链输入更多，属解释性强对照。

原始MD标签用于精确复现已有评估；统一观察窗口是0—100ns，200ps间隔501帧，每链Cα独立Kabsch拟合到窗口首帧再求RMSF。侧链Hχ沿用原χ表及固定三箱联合状态自然对数熵，PRO有定义χ且完整时有效，只有A/G无χ无效。全部53条足够长的本地轨迹均纳入，A00MI/1CLV、A00MN/1GL1、A00MU/1PPE仅0—999ps，保留成员但统一时窗标签不可用。五个100ns连续窗口仅为时间稳定性；每个体系本地只有一条轨迹，不能称独立重复。

主要评价为两组分分开、逐记录MAE，重复PDB先合并，再PDB等权与连通组等权。报告Full相对每个基线的成对绝对误差增益和家族整簇bootstrap95%区间，10000次、种子20261026。明确不能将残基、时间帧或匹配位置对作为独立样本。侧链原值相关可能受氨基酸类型影响，补充同类型位置对分析。

主匹配为同一链同一种氨基酸、参考RMSF差≤0.10 Å，0.25/0.50为宽松敏感性；另作侧链SASA差≤10 Å²（5/20敏感性）并保留链端距离、主链局部构象和接触数信息。全部合格无序位置对枚举，同一AA先平均、再记录/PDB/连通组平均，避免某类大量重复残基对主导。匹配依据参考标签仅用于解释，不称部署可用流程；覆盖不足必须报告。分类、对照、mask检查、正负结果都保存。
