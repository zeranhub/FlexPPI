# 图3图注与叙述建议（版面研究稿，未写入Word）

**图3｜复合物上下文下主链与侧链柔性的互补呈现。** a，将Full模型的主链RMSF预测映射到1MXE中CaMKI调节肽的实验结构；W303与M316标示文献确定的两个CaM结合锚点。b，在相同坐标、相机、缩放和裁切范围下，将Full模型的侧链构象熵Hχ映射到侧链；灰色主链提供连续的结构定位，CaM仅作真实环境参照。两幅图采用相同连续色系，但分别使用各自带单位的绝对数值色标，颜色不表示蛋白组分或不同复合物。c，完整显示CaMKI 294—318位的Full与Intra预测，主链RMSF和侧链Hχ共享残基坐标与序列；浅色区域标示W303—M316跨度。W303/M316用于主链位置定位，N297/N308用于同种氨基酸的主链与侧链对照。A299、A306、A309和A311没有可定义的侧链χ熵，对应曲线保留为空缺，结构中以灰色显示。两模型接收相同的结合态输入；Intra不是游离态。因此曲线差异反映模型上下文处理的区别，不代表游离—结合过程的实测变化。空间图沿用固定实验坐标，不代表生成的运动轨迹。

**局部环境显示说明，接在b的图注后。** b中较清晰的灰色表面仅显示两个Asn侧链重原子5 Å邻域内的真实CaM原子，表示空间邻近，不是完整CaM表面或定量埋藏面积。N297该邻域没有CaM原子，N308的邻域来自CaM E11、A15、L18和M72；距离按固定实验坐标计算。侧链表面遮蔽的定量比例仍来自单独的可及面积计算。

**可据数据展开的正文。** 在W303—M316这段由既知双锚点界定的跨度内，Full模型给出的主链RMSF为0.447—0.689 Å，形成连续的低波动区域；与此同时，这段中的侧链Hχ并非统一降低，提示主链位置受限和侧链状态多样性可以同时存在。为避免不同氨基酸种类及χ角数目对原始Hχ比较的影响，可进一步考察同为Asn的N297和N308：Full预测的主链RMSF分别为0.809与0.448 Å，Hχ分别为1.587与0.601 nats。固定1MXE构象的表面计算中，移除CaM而保持肽坐标不动时，N297的侧链可及面积基本不变，而N308约84.3%的侧链可及面积受到CaM遮蔽。该对照将预测差异与具体空间环境联系起来，但未单独分离出序列位置、邻近作用及局部结构等因素的因果贡献。

**机制推断的措辞。** 结合既有双锚点结构与自抑制序列重叠的背景，可以提出双锚点及其间的主链约束有助于维持调节片段从催化核心移出的状态，从而降低抑制接触重新形成的可能性。现有模型读数提供这一假说的动力学线索，并未测得活性或证明抑制接触的形成速率；不能把Full与Intra分别命名为结合态与游离态，也不应由本图推出严格的结合先后顺序。若验证此假说，应在匹配CaM结合占据率的条件下，同时检验局部约束与活性的变化。

**结果使用限制。** 这不是“每个关键位点Full都更准”的论证。N308的单点Hχ误差并不优于Intra；本图主图未叠加MD，不能单凭此图宣称预测精度。完整预测与参考值及原有误差评估仍保留在源数据和既有验证材料中。不同种类侧链的原始Hχ不直接等价于可比的自由度；更高Hχ表示本定义下被占据的离散角度状态更丰富，不能表述为转动更快。
