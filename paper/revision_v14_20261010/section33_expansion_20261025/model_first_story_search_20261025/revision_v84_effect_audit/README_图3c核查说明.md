# 图3c模型效应核查版

本版只用于核查并改进图3c的区域选择，未替换论文DOCX或整张图3。全部预测来自既有固定Full模型，沿用v83原始数据。NHE1为棕色圆点，IQCG为蓝色方点，与论文已有状态配色一致。

## 建议图注

CaM在NHE1与IQCG复合物中的预测柔性。左侧依次为全序列主链RMSF与侧链Hχ原值；框线标出37–45和111–119区，点标出R37、N42与N60。右上为两个区域的主链RMSF均值，右下为三个侧链位点的Hχ原值。37–45区的RMSF均值由1.842降至0.802 Å，Hχ均值由1.930降至1.468 nats；111–119区RMSF由2.006降至0.947 Å，Hχ均值由2.005变为1.952 nats。R37和N42的Hχ分别由3.212降至1.761、由1.510降至0.760 nats，而同为Asn的N60由0.837升至1.689 nats。区域均值中RMSF各纳入9个位点，Hχ分别纳入7和8个有效侧链位点。连线仅连接同一位点或同一区域在两种复合物中的预测原值。

## 选择依据及解释边界

先按模型输出检查所有连续九残基窗口和全部有效侧链，再确定本核查版的重点；属于探索性选择，不是事前指定。保留全部145个RMSF位置和122个有效Hχ位置，两种状态合计534个全序列原值；Hχ缺失位点保留断线。四个坐标轴均从0开始，全序列范围保留RMSF 0–4 Å、Hχ 0–4.1 nats，未用截断纵轴放大差异。

原来M72的RMSF仅0.877→0.810 Å，绝对变化排第138/145；M109有较大主链下降，但侧链变化较温和；M144变化居中。这些Met不适合继续作为三个同等重要的强变化热点。37–45区主链9/9、有效侧链7/7均预测降低；111–119区主链9/9降低，侧链平均值变化很小。全蛋白|ΔHχ|中位数约0.098 nats，不应描述为普遍大幅侧链变化。

MD参考值仅保留在可追溯源数据中，本图不绘制MD曲线。37–45区的MD区域平均主链和侧链变化同向，R37、N42、N60的MD侧链变化也分别为降低、降低、升高。连续时间窗来自同一轨迹，不能当作独立实验重复。上述比较不构成独立实验因果验证；全链拟合RMSF包含叶间相对运动，Hχ是既定离散定义下的联合熵，不能直接解释为旋转速度。训练集案例不用于宣称泛化性能；伙伴、总体构象及原始结构背景存在共同变化。
