# CaM 两态共同参考系结构图（v82）

最终全结构图为 `whole_NHE1_trim.png` 和 `whole_IQCG_trim.png`，两者均为透明背景、2280 × 1606 像素。两个文件使用同一个正交相机、同一埃/像素比例和同一个裁边框，可以在排版中赋予相同宽度；不能再按各自蛋白的外接框独立缩放或独立居中。未裁边原图为 `whole_NHE1.png` 与 `whole_IQCG.png`（2600 × 2718）。`render_manifest.json` 包含最终相机、共同裁边框、M72 和 M109 末端碳原子 CE 在原图及裁边图中的像素坐标、原始输入 SHA256 和几何审计。

CaM 的两种输入构象本身不同。为了让整体结构在共同参考系中比较，以成熟编号 7–19、65–75（N 叶瓣螺旋 I、IV）的 24 个 Cα，对整个 IQCG–CaM 复合物作一次最小二乘刚体拟合，参考 NHE1–CaM；该参考点组拟合 RMSD 为 1.313 Å。随后两个完整复合物共同旋转到同一个显示方向，使 NHE1 的 N 叶瓣位于左侧、C 叶瓣位于右侧。两叶瓣不作各自独立的移动，因此保留了真实的叶内与叶间差异。这个对齐用于明确图中的空间参考，不能用作两态整体同构或“只有肽链不同”的证据。

颜色沿用既有图版：N 叶瓣深蓝 `#2166AC`，C 叶瓣浅蓝 `#85ABD1`，连接段灰 `#A6AEB4`，伙伴肽暖赭 `#B87936`；关键残基侧链碳青绿 `#3A8D8C`、硫金色 `#B18F31`。两条 CaM 链及两条伙伴肽均为完整连续卡通，侧链按输入坐标显示，不补建原子、不重建缺口、不加入钙离子。部分 M72 侧链会被前方卡通遮挡；其投影坐标仍可用于定位，但不应把遮挡解释为缺失原子。

可编辑会话为 `CaM_shared_reference_v82.pse`，内含 `NHE1_shared_view` 和 `IQCG_shared_view` 两个场景。复现脚本为自包含的 `render_shared_view_v82.py`，它直接读取同目录 `inputs/` 中的两个原始 PDB。运行方式：

```powershell
& 'D:\Anaconda\envs\pvb_cpu\python.exe' '.\render_shared_view_v82.py' --angle 60
```

这里的 60 度是围绕共同 N→C 显示方向的相机选择参数，不是将某个叶瓣旋转 60 度。`shared_view_contact_sheet.png` 为选择最终视角时生成的六组小预览；最终 PNG 和 manifest 才是正式排版来源。原始 PDB 及所有几何数据保持不变，仅移除显示对象中的氢，完整复合物内部距离经检查保持不变。
