# 图3数据定义与复现

图3回答同一CaM序列处于NHE1与IQCG两种识别构型时，模型能否捕捉主链运动减少及侧链构象占据双向再分配。图a把两个实际输入结构与全体122侧链变化对应放在同一panel；图b共用成熟编号，集中展示两项预测、EF-hand环及接触轨道；图c、d分别保留完整接触分组和全部九个Met；图e把M72/M109的真实局部结构与两项变化直接邻接。没有删去不准确位置，也没有对曲线平滑或点抽样。

数据均来自既有MD和已运行的冻结模型预测，未在本次重绘中新增模拟或重新选择模型。A004C与A007U分别源自2YGG与4LZX。CaM共有成熟编号4–148的145个相同氨基酸位置；侧链比较排除Ala/Gly/Pro及无效角度，保留122位。两态均在第0折训练中，因此是训练内解释案例；本图不承担独立外部泛化验证。Full与Intra权重、训练归属、结构来源的路径与SHA见source_data/training_member_completion.json。

所有变化为IQCG减NHE1。RMSF单位Å；Hχ单位nats，为论文固定粗角区下的多角联合状态占据熵。参考是两态各一条500ns轨迹的五个连续100ns窗口。各态按原标签规则，用该态完整CaM链逐段拟合该段首帧后计算RMSF；A004C拟合146位包含表达尾Ala149，比较时提取145共同位。独立拟合叶瓣属于额外对照，不能与整链标签混写。五个窗口是同一轨迹的时间分段，不是独立重复。未作显著性检验或把窗口极值当置信区间。

图a每点为一个侧链，共122点。Spearmanρ针对两态变化而非绝对值；MAE是逐位绝对变化误差的平均。Full=0.170828、Intra=0.233698nats。青绿点代表IQCG初始输入接触范围，包含仅IQCG接触和两态接触。图b分别展示全部145个RMSF变化和122个Hχ变化，侧链缺口是指标无定义，并非删除不准确点。纵轴单位分别标出，不共享数值色标。

图c仅凭输入结构界定接触：跨链Cα距离≤8Å。四个互斥组8/21/3/90位覆盖全部122侧链，组内等权均值；灰点是每个连续窗口的组均值，灰圆为五窗口平均，蓝方为Full平均。图d包括全部九个Met的MD/Full变化，灰线是五窗口的最小到最大值；M36方向错误与M124幅度错误完整保留。图e中M72两态均非直接界面，M109仅IQCG态接触。它们的结构是模型输入快照，变化数值来自MD和标量预测，模型不生成这些侧链朝向。

PyMOL采用完整连续cartoon选择，原结构没有CA或肽键断点；紧近景由相机自然裁边，不再用空间球形选择截碎cartoon。全结构按N叶对齐，局部按±5位置骨架对齐，仅对显示对象施加刚体变换；没有改原子内部坐标。原始PNG/PSE、manifest和连续性逐链检查在../pymol。论文palette为Full蓝#2166AC、暖赭#B87936和青绿#3A8D8C，替换了旧图Full红色。
