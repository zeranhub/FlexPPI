# 图S3：CaM参考核查

本目录承接从主图3中移出的MD参考及准确度比较。主图用于呈现模型在两种情况下预测的柔性模式，图S3保留核查所需的参考数据。未运行新模型，也未重新估计MD量。

`compose_figS3.py`可独立运行，包含学术作图要求的字体、颜色和导出基线。`panel_body.py`为同一面板代码的编辑副本；复现时以`compose_figS3.py`为准。输出为183×145 mm的PDF、可编辑文本SVG，以及450 dpi PNG；PDF字体已嵌入。

源数据从v82图3的`source_data`逐字节复制。a为122个位点各两态绝对值，共244点；b为同一122个位点的IQCG减NHE1变化量；c为145个位点各两态MD主链RMSF，共290个有效读数；d为122个位点各两态MD侧链Hχ，共244个有效读数。缺少侧链读数的23个位置在序列上保留为空缺，未跨越缺口连接，也未补值。所有面板共900条绘制记录，可在`source_data/figS3_all_plotted_values.csv`中逐条追溯。

变化量指标由`md_b−md_a`和`full0_b−full0_a`直接计算，并与原表存储的差值列逐点核对。Spearman ρ=0.6296027043727964，MAE=0.17082836576661126 nats。五个连续100 ns窗口不作为独立重复，两条记录均为固定fold 0训练内记录，不能用作独立泛化证据。

已视觉检查完整PNG，未见文字重叠或裁切；所有有限源值均在坐标范围内。`figure_QA.json`记录计数、指标及SHA256哈希。
