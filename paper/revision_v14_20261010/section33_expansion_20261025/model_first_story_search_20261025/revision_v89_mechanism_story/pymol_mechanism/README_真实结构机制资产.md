# v89 真实结构机制资产

建议主图使用 `1A06_context_trim.png` 与 `1MXE_context_trim.png`。前者完整保留自抑制 CaMKI 的观测激酶背景，后者完整保留 CaM 双叶瓣背景；紫色为观测调控片段，青色为 K296/F298/W303/M316 的实际侧链。两图保留同一相机旋转矩阵，分别 zoom 以便在印刷尺寸下看清。它们没有统一整体尺寸；如需严格相同光学比例，可对照 `1A06_overview_trim.png` 和 `1MXE_matched_scale_trim.png`，但 CaM 结构会自然较小。`1A06_overview_trim.png` 为不透明激酶版本；context 版本将激酶 cartoon 设置为 30% 透明，以显示调控段。图中无文字，便于由主图脚本加入矢量标签和引线。

关键几何事实：1A06 中 F298 侧链与 G214(2.975 Å)、I210(3.522 Å)、F104(3.801 Å)、Y184(3.922 Å)、P216(3.928 Å)、Y215(4.47850 Å) 有≤4.5 Å重原子近邻，共六个对象；这是最适合在自抑制背景中标出的远端接触。K296 NZ 最近 E292 OE2 为 3.080 Å，但 E292 是序列相邻调控前段；K296 对编号<280的远端激酶重原子最近 Y241 为 6.174 Å，因此不能把 K296 画成一个直接扣住远端激酶口袋的锁扣。1MXE 中 K296 NZ 与 CaM E127 OE2 为 2.744 Å，F298 侧链与 CaM L116/E120/M124 最近距离为 4.071/4.072/4.465 Å。

四个关键侧链的观测重原子齐全；1A06 观测调控片段只到 M316，没有 R317/K318，不进行补模。1MXE 是 CaM 与独立调控肽的复合物，没有激酶催化域；不能标成完整激酶已激活的结构。两张静态结构不能给出结合时间顺序、完整构象路径或自抑制接触返回概率。机制图可把这些作为明示的假说，而不是结构直接测量结果。

`render_manifest.json` 提供每个 trim PNG 的尺寸、裁剪框、K296/F298/W303/M316、F298 口袋、G214/F104/I210、CaM N/C 叶瓣及 CaM 接触残基的投影坐标。像素原点在左上；主图放置图片后，可按目标宽/高分别线性缩放投影坐标。所有标记来自真实选择的原子坐标，没有手绘位点代替。`all_context_min_distances.csv` 为这四位点对全部上下文残基的重原子最短距离，分别保留 whole-residue 与 side-chain 两种定义。`independent_geometry_audit.json` 逐个从 PSE 重新读取并验证坐标和相机，五个全景资产均与冻结输入完全相同，最大坐标变化为 0 Å。所有 PNG 透明背景、800 dpi 元数据；PyMOL 会话、输入 PDB 和脚本齐全。

完整距离CSV与接触JSON均保留F298在4.5 Å内的全部六个背景残基：G214、I210、F104、Y184、P216及Y215。Y215的最近接触是F298 CE2到Y215主链CA，距离4.4784965 Å，并非Y215侧链原子的接触。`F298_pocket_trim.png` 为便于在23–28 mm局部图内辨认，只将较近的五个邻居画成深灰sticks；Y215仍以完整激酶cartoon背景存在，没有移除原子，但没有额外显示sticks。因此该放大图仅展示局部接触环境，不应称为“全部接触残基”或声称仅有五个邻居。独立重载`F298_pocket.pse`核查：Y215有12个原子、12个cartoon显示原子、0个sticks显示原子。未重做图、未修改坐标或距离数据。
