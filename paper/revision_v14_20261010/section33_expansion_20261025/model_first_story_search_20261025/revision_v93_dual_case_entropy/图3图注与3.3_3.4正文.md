3.3 典型识别体系中的主链约束与侧链环境差异



为说明两个预测读数如何对应到可解释的结构特征，我们分别选择CaM–CaMKI复合物的主链RMSF和泛素–UBA复合物的侧链Hχ作为实例。每个实例先在完整有效位置上核对模型与MD参考，再分析关键区域或同类型侧链，避免仅凭个别成功位点解释模型。两例分别回答连续调控片段的主链约束能否被恢复，以及相同侧链类型在不同局部环境中的取向多样性能否被区分。

CaMKI的调控序列与自抑制区域重叠，CaM结合需要重新组织该片段与激酶的相互作用；1MXE显示CaM两个叶瓣包绕294–318号靶肽，以W303和M316分别结合C端及N端叶瓣，形成1–14识别模式[29,30]。采用全组成链家族划分第1折留出预测，Full在全部25个靶肽位置上的RMSF MAE为0.115 Å，Intra为2.383 Å，Spearman相关分别为0.803和0.419（图3a、b）。Full恢复了低波动的连续核心，而Intra整体高估其波动幅度；两模型使用相同的结合态输入并分别训练，其差别不代表真实游离与结合状态之间的变化。

从结构与预测的对应看，W303–M316核心的MD平均RMSF为0.553 Å，Full为0.513 Å，Intra为2.666 Å；其余11个位点的MD与Full均值分别为1.089和0.919 Å。W303和M316在起始结构中分别接触9个和6个CaM残基，较低波动并非只出现在两个锚点，而是连续跨越其间的调控片段（图3b）。这一分布与CaM通过双锚点稳定调控片段的结构图景一致，也为其参与维持自抑制解除后的构型提供动态线索；由于1MXE不含激酶催化域，本例不能直接检验调控片段的回接触或酶活性。Hχ预测也与参考较一致，全体系MAE为0.193 nats，但Full与Intra的侧链曲线总体较接近，故主图集中呈现主链结果，侧链与全体系核查保留在图S3。

泛素–UBA复合物2QHO提供同类型侧链的局部环境对照[23]。使用原体系划分第0折留出预测，模型在泛素全部66个有效Hχ位置上的MAE为0.080 nats，Spearman相关为0.979（图3c）；原始掩码中无χ角的位置保留为空缺。为避免将氨基酸种类之间的差异误认为环境识别能力，进一步单独比较全部六个谷氨酰胺：其侧链角数相同，模型的类型内MAE为0.105 nats，排序相关为0.943（图3e）。这些位置并非都具有相同暴露程度或相同状态多样性，提供了对类型平均值之外位置差异的直接检验。

其中，Q41侧链位于紧密堆积的内部环境，起始结构侧链SASA为0.0 Å²，MD与模型Hχ分别为1.890和2.000 nats；Q62更暴露于溶剂，SASA为100.67 Å²，对应Hχ为2.631和2.684 nats（图3d、e）。模型恢复的两位点差为0.684 nats，接近参考差0.741 nats。局部全残基棍状表示将这种状态多样性差别与实际堆积邻域对应起来。这些差异与局部堆积、溶剂暴露相关的取向限制相一致，表明模型能够恢复同类型侧链在不同环境中的状态多样性差异。全部六个谷氨酰胺并不随SASA单调排序，因此不能将Hχ简化为暴露面积的单因素函数；Q41与Q62均无5 Å以内的UBA直接接触，故这里反映泛素自身的局部环境，而非两个位点上的直接伙伴效应。实际MD联合状态占据与主链核查见图S2。

3.4 侧链预测与构象占据及相对自由能角区的对应



为进一步检验侧链输出的构象含义，我们将体系留出预测与83条记录的MD角度占据对应。该队列包含ATLAS、DynaRepo及ITrace的30、23和30条记录，不限于蛋白复合物；各记录统一使用第一条轨迹的0–100 ns、200 ps间隔501帧。除监督所用的粗箱多角联合Hχ外，从同一批轨迹另计算逐χ角5°细箱熵，以及经验投影F*=−ln[p̂(q)/p̂max]下F*≤1角区的总宽度[3,24,25]。后者等价于密度至少为峰值1/e的全部角区总长度，以°/角表示，不需要假定所有来源具有相同温度。两项均是已有MD导出的更细角度占据描述，不能等同整体蛋白构象熵或结合自由能，定义与敏感性见补充材料E。

控制记录内氨基酸类型后，Full Hχ与细箱熵的平均Spearman相关为0.510，高于Full RMSF的0.321；与低F*角区总宽度的相关分别为0.400和0.239（图3f）。因此，Hχ与RMSF并非只提供同一柔性强弱排序的两种尺度：主链位置波动不能完全替代侧链角度占据多样性，Hχ更直接地对应这些侧链构象描述。Intra Hχ的两项相关为0.493和0.391，完整模型在此分析中的额外改善较小，不能将其解释为复合物上下文对自由能的全面提升；三种输出的完整对照见图S4b。

进一步仅按预测值在每条记录的同类型位置内选取低、高两半，再读取实际MD占据指标。按Full Hχ筛选的低、高组，其平均细箱熵分别为2.498和2.791 nats/角，低F*角区宽度分别为35.41和43.17°/角（图3g）；相应高低组差为0.293 nats/角和7.76°/角。这种由预测确定分组、再检查MD占据的结果，说明Hχ可以帮助定位实际角度占据更丰富的位置。上述指标来自同一MD来源而非独立实验，泛素逐角分布的局部核查见图S4c、d；其中自由能曲线由MD占据统计得到，不是模型输出。
