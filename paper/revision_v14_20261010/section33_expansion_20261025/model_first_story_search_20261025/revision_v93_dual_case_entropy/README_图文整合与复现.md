主图a定位CaMKI的W303/M316；b呈现全部25个RMSF位置及真实CaM接触数；c保留泛素全部66个有效Hχ位置；d合并整体结构定位和两个完整残基邻域放大；e保留全部六个Gln的预测、MD和暴露程度，无SASA拟合；f呈现83记录的同类型相关；g展示仅按Hχ预测分组后实际MD细箱熵与低F*角区宽度。图内不放表格或灰色说明小字，预测/参考和蛋白组分的颜色分别固定定义。主图字号9pt，在Word中164mm宽印刷时不低于8.06pt。

1MXE用既有全组成链家族划分第1折冻结预测；泛素与83记录使用原体系留出预测，并非本轮类别分析新family预测。Full/Intra是相同结合态输入的分别训练模型，不是游离/结合实验状态。Hχ是固定粗箱的多χ联合状态熵，不是整个蛋白的构象熵。F*由MD角密度计算，为无量纲经验相对投影；模型没有生成结构集合或直接预测结合自由能。

泛素六个Gln不随SASA单调排序，Q41/Q62也均无5 Å内UBA直接接触，结论限于该结构中同类型侧链的局部环境差异。原66有效位点掩码保持不变：三个Pro有定义的两个χ角始终落入同一个粗箱，Hχ=0合法，不表示没有运动。原始全5001帧独立检查、原标签/预测NPZ及逐值核对在`ubiquitin_audit/`中。非Pro63点仅是敏感性，不替换主分析。

## 文件与重绘

`figure3/compose_fig3_v93.py`可直接从同目录`source_data/`和`../pymol/`重绘主图；使用numpy、pandas、matplotlib、Pillow，Arial字体。`entropy_audit/plot_supplement_S4.py`从已打包的冻结表重绘补充图。已打包PNG/PDF/SVG，PDF中图表为矢量，原生PyMOL结构为高分辨率嵌入图像，不能称整个主图都是纯矢量。

`render_structure_assets.py`从`pymol/inputs/`的两份真实结构和固定相机重绘4个结构资产，需PyMOL 3.0.0；`.pse`是可编辑原生会话。总览纯丝带无孤立棍状；局部选取距目标侧链任一重原子5 Å内的完整残基，全部已观测重原子画成棍状，淡色丝带作背景。两局部共享相机旋转、光学比例和图像尺寸。`audit_saved_structure_sessions.py`实际打开保存的PSE，逐原子核查坐标、完整残基选择和表示，不只检查渲染清单。

`audit_and_export_figures.py`逐一复核主图908个绘图值及SASA，并重新生成83记录的来源分层重抽样索引与全部24行汇总区间。种子20261026，10000次；这是记录层面的描述性区间，不是家族整簇区间。全部记录均参与，不把残基、帧或共享位点对当独立样本。原始统计与本轮重绘源表均保存。

`manuscript/final_text_contract.json`保存主文修订与图注；`build_v93_manuscript.py`及build审计保存Word修改过程，仍需原v90文档与本机打包文档运行时。原Word保留，新稿另存v93。文档渲染图用于内部检查，不作为独立交付正文。最终源文件包不包括原MD轨迹、训练数据、渲染临时文件夹和源Word拆出的重复媒体，但包含图表复现数据、结构输入/PSE、正文与全部审计。
