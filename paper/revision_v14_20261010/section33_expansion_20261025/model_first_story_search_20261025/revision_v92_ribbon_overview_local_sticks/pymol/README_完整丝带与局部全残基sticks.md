# V92 结构定位与完整局部邻域

最终文件：overview.png（2800×2154）、zoom_N297.png 和 zoom_N308.png（均2800×2464）；对应 PSE 与白底合成预览同名另存。三个 PNG 是透明背景，直接由 PyMOL 原生光线追踪生成。preview1400 保存实际看过的1400 px级候选。render_manifest.json 的 assets.overview / zoom_N297 / zoom_N308 提供 png、white_preview、pse、width/height、view、crop 与 named_landmarks。所有25个肽位点均有 CA / sidechain_center 二维像素坐标及原始三维坐标；N297、N308、W303、M316 可直接用于外部矢量标签。overview 为所有144个观测CaM残基（原生编号4–147）和25个观测CaMKI残基（294–318）的完整结构，没有补建未观测原子。

overview 只显示丝带，没有任何 sticks 或 surface；CaM 为 #BAC1C7、cartoon透明度0.32，肽为既有论文组分紫 #8B72A5。这里颜色只区分结构组分，不表示 RMSF/Hχ，定量曲线留给下方c。镜头保留横向靶肽，N端在左、C端在右。

两个局部使用同一刚体旋转、相同视角、同一光学距离、同一画幅，只将视图中心分别移到目标Asn侧链的几何中心。按照“任一重原子距离目标侧链任一重原子不超过6Å”的统一规则先选择完整残基，再将这些残基的全部重原子显示为 sticks（主链 N/CA/C/O 同样包括）。目标Asn全部8个重原子统一 #3A8D8C、半径0.19Å；其余邻域原子统一 #B9C0C5、半径0.12Å；不按元素上色，不画surface，不添加接触箭头。范围外不显示sticks，但保留透明度0.86的浅灰丝带背景。

N297选入1个CaM残基（E14）和6个肽残基（K295/K296/N297/F298/K300/S301），总61个重原子。N308选入7个CaM残基（E11/A15/L18/F19/M72/K75/E84）和9个肽残基（K304/Q305/A306/F307/N308/A309/T310/A311/V312），总125个重原子。两幅局部的共同窗口根据两者所有完整邻域原子的投影联合决定并留边距，因而没有切断边界完整残基。背景cartoon可以超出局部图边界；全部 sticks 的原子投影均在画幅内部。

注意6Å图不能再说“N297附近完全没有CaM”，因为其最近CaM原子在5.991Å，E14因此按统一规则纳入。两局部表达真实静态环境差异和邻域拥挤度，不能把这个截断规则直接当成埋藏比例。84.3%的N308遮蔽比例是另行SASA分析，定义不同。

独立审计 independent_geometry_representation_color_audit.json 直接读取保存的PSE，检查了源1344个重原子全部保留且坐标与重新加载PDB完全相等（最大变化0Å）；overview实际rep sticks数为0；N297全部61/61、N308全部125/125预期完整残基重原子均确实处于sticks表示，范围外stick数为0，所有场景surface数为0。目标/邻居的逐原子RGB符合统一颜色（仅浮点舍入约10⁻⁸），局部旋转、光学距离和画幅完全一致。没有新模型预测、MD模拟、自由态或机制路径。
