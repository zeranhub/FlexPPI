# 1MXE结构渲染：来源、表示与复现

本目录使用家族留出第1折的实际模型输入结构 record_aba5e1f3db118b0aba8895de.pdb，文件包含 CaM 与 CaMKI 调控肽的1344个重原子。该结构是经过原数据流程处理的1MXE体系，不把它冒称未经处理的原始晶体结构；没有为了绘图补建原子或加入钙离子。与训练载荷 A001K.pdb 的1344个重原子按原子名、链、残基编号逐一比对后，所有坐标完全相同。训练载荷额外包含氢原子，因此两个文件的字节哈希不同。详见 coordinate_audit.json。

为使图与正文采用原生生物学编号，只作编号更换：链A的1–144改为CaM 4–147，链B的145–169改为CaMKI 294–318。25残基靶肽序列为IKKNFAKSKWKQAFNATAVVRHMRK；W303与M316为相隔13个序列间距的1–14锚点。编号改动前后坐标最大差值为0 Å。

结构配色沿用全文协调方案：CaM N端叶瓣为#8A9299，C端叶瓣为#BAC1C7，连接段为浅灰；靶肽为#8B72A5；W303/M316与N297/N308的碳骨架为#3A8D8C。氮、氧、硫采用相应元素色。数值曲线的Full蓝色与Intra暖色不在此作为组分色使用。

overview.png为完整体系总览；overview_trim.png只裁去透明边缘，没有改变结构宽高比。local_303.png与local_316.png保留与总览严格相同的旋转方向，两局部的光学比例也相同。局部保留完整链的连续cartoon，通过相机放大形成画面边缘裁切，不删除链段、不使用球形空间选择切碎cartoon。纵深裁切范围设置充分宽，防止近裁切面把螺旋拦腰截断。局部棒状显示为锚点侧链与距离锚点侧链重原子不超过4.5 Å的CaM整残基侧链，该邻接标准只定义静态结构环境，不视为相互作用能或动力学机制证明。

每张PNG有独立的同名原生PSE，保留可编辑原子、选择、表示与相机。render_manifest.json记录相机矩阵、透明区域、关键原子投影像素坐标与局部接触残基。坐标是相对于PNG左上角；overview_trim的投影另按裁切框作了平移。W303标注指向CZ2，M316指向CE，N297/N308指向CG；CaM叶瓣与靶肽整体锚点为各自CA几何中心。局部图里画面外的标注坐标仍然保留，不应在合成图上硬放进视野。

复现：用 D:\Anaconda\envs\pvb_cpu\python.exe 执行render_1MXE_v85.py。脚本设置该环境的DLL路径并调用PyMOL 3.0.0。三张PNG为透明背景、600 dpi，画布总览2100×1500像素，局部1200×1500像素。结构渲染不含文字，最终图的可编辑标签由父级matplotlib脚本按投影坐标合成。
