# CaM 四伙伴原始 NMR 描述统计

本目录重新解析 BMRB 原始 NMR-STAR 文件，描述同一 CaM 结合 CaMKK、eNOS、nNOS、smMLCK 四种肽时的实验读数。没有读取任何新旧模型预测，没有重训、拟合、显著性检验或作图。这里的实验现象可用于确定值得验证的生物学问题，**当前 FlexPPI 是否能预测该现象尚未在本目录验证**。

四组来自 BMRB15183、15185、15191、15186。它们均通过既有结构—实验肽序列检查：可对齐位置一致性至少95%、双向完全一致残基覆盖至少85%；具体肽序列、身份和覆盖见 `four_partners_peptide_match_gate.csv`。通过阈值不表示构建体完全相同，末端差异和完整实验条件仍需在确认性验证前核对。CaMKI/15184 和 PDE/15187 未纳入本次四伙伴比较；游离 CaM/15188 也未纳入。

共同位点严格定义为“同一种读数 + CaM实体序列位置 + 相同氨基酸 + 相同原子名”，只取四种伙伴都有值且每种伙伴内没有歧义重复记录的交集。所有四份CaM实体序列相同，每条观测的氨基酸与原始实体序列逐一核对。最终得到87根主链N–H探针（87个残基），以及44根甲基轴探针（**34个残基**，同一残基可有两根甲基探针）。两类探针测量对象不同，不能把两者的数字差异当成校准后的运动幅度之比。

按CaMKK、eNOS、nNOS、smMLCK顺序，87根共同N–H探针的平均S²分别为0.9362、0.9240、0.9183、0.9294；44根共同甲基探针的平均S²分别为0.5348、0.5383、0.5459、0.5486。对每根探针计算四个伙伴中的最大S²减最小S²，N–H探针该范围中位数为0.043，甲基探针为0.170。适当的描述是：**各结合态的全体共同探针平均值相近，但逐位置的运动受限程度随伙伴发生重新分配**。这不是等效性检验，不能说整体动力学完全不变；主链也存在少数变化较大的位置。

原始记录中每根探针还给出拟合误差。四伙伴甲基探针的拟合误差中位数分别为0.0095、0.0095、0.0070、0.0120，主链探针对应为0.0070、0.0100、0.0140、0.0100。对每根甲基探针，取构成其最大最小差的两条记录，将它们的拟合误差相加；该误差和的中位数为0.024，44/44根探针的跨伙伴范围均大于各自两端误差和，逐探针“范围/两端误差和”的中位数为7.796。主链相应误差和中位数为0.020，73/87根范围大于各自误差和。这里只是读数变化相对于已报告拟合误差的描述性检查；最大最小值来自四伙伴中选择的极值，fit_error不是完整实验不确定性，零拟合误差也不代表没有测量误差，因此这些比例和计数**不是显著性、独立样本数或生物学重复**。

原始数据还检出两处需要保留的异常：nNOS/15191的Ile100-CG2有两条不同记录（S²为0.708与0.793），但smMLCK没有该探针，所以它不进入四方共同交集，44根共同甲基均无需重复值平均；eNOS/15185的Thr29原子被登记为非标准名CG5，原样保留而未改名，它也不进入共同交集。异常行见 `excluded_ambiguous_probe_all_partner_rows.csv` 与 `raw_nmr_input_audit.json`。未按结果大小删除任何共同探针。

87根N–H宽表在 `common_87_NH_probes_wide.csv`，44根甲基宽表在 `common_44_unambiguous_methyl_probes_wide.csv`。每行都保留四伙伴的S²和fit_error、最大最小值所属伙伴、跨伙伴范围及两端误差和。`common_probes_partner_summary.csv` 与 `common_probes_range_and_fit_error_summary.csv` 给出完整描述统计；`raw_nmr_four_partners_long.csv` 是直接由STR解析的所有四组观测，`raw_nmr_input_audit.json` 保存输入绝对路径、SHA256、实体检查和异常。S²没有转换为Hχ、RMSF、熵、结合能或亲和力；这里也没有计算游离与结合状态的差值。
