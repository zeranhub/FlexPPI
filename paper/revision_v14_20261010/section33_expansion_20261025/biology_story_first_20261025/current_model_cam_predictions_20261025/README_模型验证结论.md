# CaM 当前模型验证：不推荐作为第3.3节的强案例

2026-10-25 已实际完成模型推理。四种复合物为 CaMKK–1CKK、eNOS–1NIW、nNOS–2O60、smMLCK–1CDL；使用前一轮已核对序列与编号的第一模型，未改论文。此前的 `figure_cam_partner_dynamics` 组图只呈现公开NMR实验值和PDB结构，不能作为FlexPPI预测得到验证的图。

主要检验使用全组成链家族划分的第1折：冻结训练清单中已识别的CaM关联家族含A001K、A004C、A007U，三条均在测试集，训练集零条。权重从正式备份解压并校验SHA256；Full和重新训练的Intrachain均已运行。另跑原体系划分的五折Full/Intrachain，全部保留，不按实验结果挑选模型；这些模型存在CaM同源暴露，只作敏感性分析。每种模型均运行完整复合物及保持CaM坐标不变、删除伙伴的输入对照。

模型输出是主链位置波动RMSF及侧链扭转角熵Hχ，实验数据是NH/甲基轴的NMR有序参数S²。它们不是同一种物理量。本次只检查可预期的定性反向趋势：如果S²降低、甲基轴取向限制减弱，模型Hχ是否相应升高；不计算跨指标MAE，不把结果当成直接预测S²，也不由NH S²变化很小直接断言RMSF保持不变。

关键的nNOS→smMLCK比较使用所有可匹配、有χ角且具有共同甲基实验的残基。同一残基的双甲基先取S²算术平均，每残基只计一次。原44个共同探针对应34个残基；其中5个Ala没有χ角，另L4在smMLCK结构中无坐标，余28个。V142两个甲基的实验变化方向相反，严格方向分析将其单列，余27个；同时保留28个残基的全量敏感性结果。

| 家族排除模型/输入 | 27个明确方向残基：方向相符 | ΔHχ与−Δ平均S²的Spearman相关 |
|---|---:|---:|
| Full，完整复合物 | 14/27，51.85% | −0.0302 |
| Intrachain，完整复合物 | 12/27，44.44% | −0.3227 |
| Full，伙伴删除输入 | 11/27，40.74% | −0.1365 |

保留V142的全部28个残基时，Full方向相符15/28，相关−0.0315。Full比对照略好，但主要对应关系接近零，不能据此称为有力模型案例。四伙伴残基内去均值后的探索性相关为0.1745，亦不足以覆盖主要配对结果的缺口。普通划分五折均值也没有救回这一结果：27个残基上Full为14/27、相关−0.0189，Intrachain为15/27、相关−0.0174。保留每折结果后亦无理由挑选某一折作为成功证据。

独立计算同一CaM主链坐标下完整复合物与删除伙伴输入的差异，再比较nNOS→smMLCK的伙伴贡献变化，28个残基的整体相关也仅0.0413。L18、L105的正确方向不能据此归因于伙伴直接贡献。Intrachain在删除伙伴前后输出完全相同，符合其仅使用链内信息的设计。独立复核16份家族模型NPZ与CSV逐行差异小于9×10⁻¹⁶。

此前讲述的三个核心位点也没有完整得到支持。以下Hχ为模型原始输出；不同指标的数字大小不能直接比较。

| 位点（nNOS→smMLCK） | 实验甲基S² | 模型Hχ | 定性方向 |
|---|---|---|---|
| L39–CD2 | 0.779→0.329 | 1.0438→1.2084 | 相符 |
| L105–CD1；CD2也同向 | 0.285→0.590；0.256→0.551 | 1.2688→1.2527 | 相符，但Hχ数值变化小 |
| M144–CE | 0.680→0.354 | 2.1079→2.0331 | 相反 |

L18与M109的定性方向相符，但预测Hχ变化分别只有−0.0132与+0.0078，不据此挑出局部成功故事。不同指标的尺度不相同，因此也不将这些小数值与实验变化作比例比较。

本轮结论：CaM实验现象本身成立；当前模型在这些匹配结构上的结果不支持将其包装成第3.3节的强验证案例。它也不能证明模型的MD标签预测无效，因为NMR有序参数并非其训练目标。按用户要求，不把这个不充分的案例写进论文，不继续为它制作模型验证组图。

可复核文件：`family_predictions.csv`为主结果逐位点原始输出；`predictions_by_fold.csv`和`predictions_fivefold_mean.csv`为原体系五折输出；`family_raw_predictions/`和`raw_predictions/`保存所有前向输出与身份信息；`validation/results/family_predictions/`、`core_mean/`、`core_folds/`保存最终完整匹配表、预先指定五个位点与全体数值，最终有效结果以`validation_manifest.json`为准。`family_heldout_model/`保存正式权重、源码、配置和家族排除审计。独立重跑原正式A001K Full第4折的169×2个输出，与原OOF缓存最大绝对差3.58×10⁻⁶，链、残基编号和氨基酸逐项一致，说明运行流程与正式模型输出尺度一致。

复现入口为 `run_current_cam.py`（原体系十个模型）及 `run_family_cam.py`（主要家族排除两个模型）。这两个入口的推理阶段只读取结构和权重，不读取NMR值。实验对照由后续独立验证脚本执行。所有本轮结论针对当前匹配结构和以上明确比较，不将一个蛋白、多个位点或多折权重当成独立实验重复。
