# 以真实 XTC 时间戳重新筛选

原来仅凭留出精度和同环境残基对筛出的3AAA、4DW2、6A77等，必须先过本地原始轨迹时间审核。首次50个优先记录实读恰有25条 `0–999 ps`（0.999 ns）、25条500 ns，来源文字声称“100 ns/重复”不能覆盖文件中实际时间戳的不一致。当前将至少50 ns作为继续验证的硬门槛，并要求后续分块占据稳定性；既不把0.999 ns改写成100 ns，也不把五个时间块称为独立随机种子重复。

`audit_candidate_trajectory_times.py` 使用 MDTraj `XTCTrajectoryFile` 只读访问 XTC，读取帧数、首帧、次帧、末帧的 time 和 step。`actual_local_trajectory_time_audit.csv` 保存真实路径和时长，`candidate_ranking_with_actual_duration.csv` 为全部已审核候选，`candidates_minimum_50ns.csv` 只保留达到时长门槛的候选。源结构、XTC和metadata均不改动。

优先50条中的新进候选是 **2V5Q / A003W 链A，PLK1–DARPin**：实读500 ns；整链Full相对AA+SASA+contacts、Static47+SASA的Hχ MAE改善0.0330、0.0230 nats，同类型ρ为0.7658（Static47+SASA为0.6649），界面Full相对Intra的MAE改善0.3092 nats；有E102/E151与K105/K162两对互不重复的近SASA/近RMSF对。但其主fold不是family-clean，必须在说明中保留家族重叠边界，实际角度占据和窗口稳定性仍需核验。

具有主划分家族隔离的候选中，**3T0Y / A0064 链C** 有两对L247/L215、L248/L273，实读500 ns，全链Hχ MAE对两强基线改善0.0180/0.0224，typedρ0.6618（Static47+SASA0.5778），界面Full–Intra改善0.0647。**5NL1 / A009U 链A** 实读500 ns，全链改善0.0353/0.0217，typedρ0.5385（Static47+SASA0.3474），界面改善0.0259，有一对L26/L128。**3VYR / A00CD 链A** 实读500 ns，全链改善0.0210/0.0213，typedρ0.4623（Static47+SASA0.3353），界面改善0.1460，有一对K49/K5。这些候选的优势、配对数量与是否独立隔离分别报告，不能把满足其中一项写成全部满足。
