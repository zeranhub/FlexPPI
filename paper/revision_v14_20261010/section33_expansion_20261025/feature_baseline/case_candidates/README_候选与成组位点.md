# 强基线之后的案例候选（仅探索筛选，未改论文）

**追加原轨迹时间审核后，3AAA 暂不作为强主案例。** 其本地 XTC 实读 1,000 帧，首/末时间为 0/999 ps，虽然来源 metadata 声称 100 ns/重复，但文件时间戳与声明不一致，当前没有足够依据将这条轨迹当作经过100 ns采样的验证。三个残基对与预测数值本身可复算，但没有时间收敛保证。后续以 `candidate_ranking_with_actual_duration.csv` / `candidates_minimum_50ns.csv` 的真实时间审计和分块稳定性为优先；下面保留的是时间审核前的内部候选筛查结果，不直接用于论文。

时间审核前数值筛查最高的是 **3AAA 的 capping protein β 链**，其次是 **4DW2 的 Fab C 链**。两者均同时满足：整条目标链的 Hχ MAE 与同类型位置排序优于 AA+SASA+contacts 和 Static47+SASA；界面完整模型优于链内模型；至少三对互不重复、化学种类相同、静态暴露和真实主链 RMSF 相近的侧链仍表现出明显 Hχ 差别，且 Full 恢复这些差别。这里是从现有留出预测中筛案例，没有检验显著性，也没有构成新的家族独立验证。两者主划分均非 family-clean。

## 3AAA：三个相近环境侧链对

数值顺序均为左位点 → 右位点；编号是当前冻结输入的 B 链作者号。

| 位点对 | SASA（Å²） | MD RMSF（Å） | MD Hχ | Full Hχ | AA+SASA+contacts Hχ | Static47+SASA Hχ |
|---|---|---|---|---|---|---|
| I213 → I210 | 20.63 → 18.87 | 0.528 → 0.611 | 1.058 → 1.669 | 1.091 → 1.681 | 1.309 → 1.391 | 1.309 → 1.377 |
| I239 → I144 | 4.78 → 3.77 | 0.710 → 0.697 | 1.061 → 1.598 | 1.194 → 1.533 | 1.338 → 1.346 | 1.349 → 1.372 |
| L228 → L193 | 0.503 → 0.126 | 0.500 → 0.561 | 0.791 → 1.260 | 0.960 → 1.273 | 1.203 → 1.148 | 1.198 → 1.218 |

这些对可以支持“同类型、相似暴露和相似主链活动仍有不同侧链占据”，但不能全部归因于 V1。重原子接触实测显示：B144同时接触 CP α 的 A254（3.79 Å），以及 V1 的 C12（3.95 Å）、C8（4.02 Å）、C14（4.82 Å）；B239只接触 CP α 的 A196/A169/A198等；B210接触 CP α 的 A275/A271，B193与B228也主要接触 CP α。它们展示的是完整复合物不同局部堆积约束，只有 I144 一端直接处在 V1 接触处。若要论证“V1导致动态改变”，还需要真实不同状态的参考和正确响应，不能由此静态匹配推出。

3LK2 / A005J 是同一 CP 与 CARMIL 片段复合物，当前正确主fold同为3；β链前242位与3AAA逐字相同，3AAA另有8位末端延伸，α链也有末端截断差异。已按共同序列、排除两端10位快速检查其现有两态 OOF，内部结果保存 `CP_beta_CARMIL_3LK2_vs_V1_3AAA_common_interior_residue_deltas.csv`；该状态差尚未构成强案例，因此不建议仅因有独立文献就把3AAA升级为V1/CARMIL响应证明。

## 文件与复算

主筛选脚本是上级 `screen_case_candidates.py`，上下文核验为 `inspect_candidate_contexts.py`。`candidate_chain_ranking.csv` 保留全部已审计异源复合物链；旧616清单实际上排除的是ITrace数据来源，仍混有DynaRepo的TCR，故新增 `non_tcr_candidate_chain_ranking.csv` 明确排除T-cell receptor描述，排除记录保存在 `excluded_tcr_records.csv`。3KXF虽有较多漂亮残基对，因为它是SB27 TCR–pMHC体系，本次非TCR候选不使用。

`shortlist_five_case_metrics.csv` 和 `shortlist_disjoint_residue_pairs.csv` 保存上述候选与一个真实配对备查体系1I2M的数字；1I2M虽然可找到三个优良残基对，其整链Full并未胜两强基线，因此没有列为主推案例。`shortlist_sidechain_neighbor_contexts.csv` 给出侧链至每个邻居残基重原子的最近距离、原子名、链身份和4/5 Å接触原子数。这些距离只是结构近接触，没有被自动命名为氢键，也没有被当作动态因果验证。
