本次只审查已经存在的数值结果，没有改论文，没有重新训练，也没有开展实验或设计序列。两个体系的原始轨迹均已经独立复算并通过核验：实际保存间隔为 100 ps，5001 帧覆盖 500 ns，计算采用前 5000 帧的五个连续 100 ns 时段。复算 Hχ 与冻结标签的最大差异小于 1.2×10⁻⁷。五个时段来自同一条轨迹，不能当作五次独立重复实验。本报告包含筛选中未达到强案例标准的内部判断，不是供论文直接采用的段落。

主分析完整保留所有符合条件的配对，不要求其中一方处在界面，不按真实 Hχ 的高低差或模型误差挑选好对。条件是同一条链、同一种氨基酸在该链至少有四个有效而完整的非脯氨酸侧链、排除前后各三个位置、侧链暴露面积之差不超过 10 Å²、真实主链 RMSF 之差不超过 0.10 Å。这里用真实 RMSF 是为了检验“主链运动相近时是否仍能分出侧链差别”，属于解释性对照，不是预测时可获得的输入。原筛选脚本还限制了暴露面积在该氨基酸内部的百分位差，本次把这一项放到敏感性分析中，没有带入主配对集合。原脚本的端点距离从零计数却要求大于三，实际上会排除前后各四个位置，本次主分析准确排除各三个，并同时给出旧规则的结果。

DraG–GlnZ（A00C9 / 3O5T）可以支持“超出两个挑选位点的、同类型侧链内部排序”这一层论证，但不宜称作极强的界面机制案例。DraG 的 A 链有 219 个有效非脯氨酸侧链；完整配对集合包含 211 对、122 个不同残基和 14 种氨基酸。Full 判断高低次序正确的比例为 61.61%，Intra 为 56.87%，AA+SASA+contacts 为 50.71%，Static47+SASA 为 52.61%。真实 Hχ 高低差与预测高低差之间的平均绝对误差，四者依次为 0.24364、0.26701、0.26229、0.25627。按唯一残基计算的整条链 MAE 依次为 0.19384、0.20802、0.20257、0.20351；先在每种氨基酸内部减去均值再比较整体排序，Spearman 相关依次为 0.67787、0.63164、0.60958、0.61471。这些增益并非由一个反复出现的好残基造成：任意删去其中一个残基后，Full 相对两种强基线的顺序正确率仍至少高 8.42 和 6.44 个百分点，预测差值的误差也仍有改善。任意删去一种氨基酸后的方向优势与差值误差优势也仍为正。额外要求暴露面积百分位差不超过 0.25 后剩 147 对，Full 正确率为 64.63%，两种强基线为 49.66% 和 51.70%，结论不依赖放宽这一条件。

同一条 DraG 链中，真实差值达到 0.4 的全部 46 对涉及 56 个不同残基，Full 判断正确 35/46，Intra 为 27/46，两种强基线为 29/46 和 33/46；预测差值的误差依次为 0.45140、0.54639、0.55947、0.53252。42/46 对在全部五个时段都保持原 Hχ 高低次序，其余四对也至少四个时段同向。把每个侧链角细分为 5° 小格，并对四种小格起点取平均后，40/46 对的整段细分熵仍保持同序；若要求五个时段中至少四个时段细分熵同序，则为 34/46。用围绕常见旋转异构体中心的另一套 120° 分箱，36/46 对的时段平均熵同序，30/46 对至少四个时段同序。角宽不是相同的物理量，整段角宽只有 32/46 同序，至少四个时段角宽同序为 29/46。因此可以说“构象占据差异有时间段与分箱敏感性支持”，不能把全部 Hχ 差异改写成“侧链角度范围更宽”。

DraG 的界面配对只有 14 对；Full 的方向正确率为 64.29%，与 Intra 和 AA+SASA+contacts 相同，低于 Static47+SASA 的 71.43%；差值误差也没有优于 Static47+SASA。因此，整条链上的排序优势不能被解释成已经证明“伙伴约束决定这些侧链的运动”。GlnZ 的 B 链只有六对符合主条件，Full 也没有超过 Intra。适合保留的结论是 DraG 链内部有广泛但中等幅度的增量信息；若论文要求一个兼具明确伙伴机制和大幅基线优势的主案例，还应继续寻找。

PhyR–NepR（A0064 / 3T0Y）不建议作为新的主案例。两条 PhyR 拷贝都必须检查，不能只保留 C 链的好对。A 链完整集合为 22 对、20 个残基，Full 正确率 77.27%，Static47+SASA 为 68.18%，但差值误差 0.22566 略大于后者的 0.22306；C 链为 42 对、37 个残基，Full 正确率 64.29%，Intra 为 78.57%，Static47+SASA 为 73.81%。A 链真实差值达到 0.4 的五对全部共享 L90，不能当作五个彼此独立的残基对证据。旧候选 L247/L215 虽然原 Hχ 差值为 0.55809、五段均同序，5° 细分熵的平均差只有 0.04774，且仅两段同向；另一套旋转异构体中心分箱的平均差反向（−0.04994）。L248/L273 的细分熵和角宽支持较好，但单独一对无法解决用户指出的论证过窄问题。相关数值仅留作内部筛选，不建议写进论文。

全部结果可由同目录的 audit_sidechain_cases.py 复现。all_qualifying_pairs_with_physical_verification.csv 是不按模型效果筛选的全部 283 对，all_large_gap_pairs_no_model_selection.csv 只按真实差值分层，pair_summary.csv 包含主条件、界面分层与两个敏感性条件，unique_residue_summary.csv 避免高频出现的残基在 MAE 中被反复加权，per_amino_acid_pair_summary.csv 可检查增益是否集中于单一类型，leave_one_residue_or_amino_acid_out.csv 用于检查某个残基或某种氨基酸是否支撑整个结论。配对共享残基，因此报告没有把 211 对当成 211 次独立实验，也没有产生基于这一错误假设的置信区间或显著性。
