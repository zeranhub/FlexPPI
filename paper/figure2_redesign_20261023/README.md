本次图2的核心问题是比较方式：预测对MD的条件均值曲线能够检查偏差，却不能直接呈现四方法的总体误差；多条PR曲线重叠又使接近的方法难以区分。候选图按“预测有多准、识别高动态位点有多好、改善是否出现在许多记录上”组织。a/b直接显示四方法的记录等权MAE，横轴从0起点，较低更好；c—e以四方法分行的AP点与原95%区间直接比较三个任务，统一0—1范围；f—h显示Full相对Intra和Static的逐记录AP差，负值及并列值全部保留。每个AP差点都对应同一记录的两种方法，3,063条记录完整纳入，没有挑代表样本。

主要论点为“连续读数更准，且在同种残基内部仍能识别动态位点”，不将总体Hχ上Full/Intra的微小差异描绘成巨大提升。Full相对Static的两项MAE分别降低14.8%和11.3%；同类型Hχ的Full AP为0.623，AA为0.146，说明模型的位点识别能力超过类型均值先验。总体Hχ的Full相对Intra平均AP仅高0.59个百分点，配对图保留这一实际量级及表现变差的记录。

`plot_performance.py`为重绘入口。`source_archive/`完整保存这次构图使用的两份逐记录表、冻结统计协议、记录映射、汇总及来源结果，均与原归档逐字节相同。AP及95%区间直接沿用原结果；没有新训练、推理、显著性检验或新增MAE区间。配对差、改善记录比例与分位数是从同一记录原指标直接计算的描述统计。坐标值没有平移；配对散点仅在竖直方向分散，便于辨认。

原来的完整预测密度、四方法分箱曲线、完整PR及三来源AP矩阵保存在`supporting_original_validation.pdf`，与v61采用的图2相同。本候选将这部分作为配套证据，尚未将其正式移入论文补充材料。导出为183×185 mm的矢量PDF、可编辑SVG和450 dpi PNG，文字最小9 pt；印刷尺寸预览见`print_preview.png`。完整的逐记录AP差表、均值与区间表及QA同时提供，便于检查。
