# KRAS G12D替换正文：科学主张审计

审计对象为v40中的SB27/SB47与Q7实例。本文本仅提供替换建议，未编辑DOCX。正文以同一完整结构主模型为准；此前strict模型的较高成绩不用于主文。其余KIX、泛素、83条记录的自由能与侧链占据验证保留。

## 数值与重复口径

独立读取`itrace_case_search_only_20261017/promising_cases_replica_validation/7ow5_7ow6_all_positions_three_replicas.csv`，以G12D减野生型重算。全部10肽RMSF变化：Spearman 0.8060606061、MAE 0.2288818616 Å、9/10方向一致；去G6/D6后全部9个位点：Spearman 0.7333333333、MAE 0.1815093493 Å、零变化基线MAE 0.3033328526 Å、相对改善40.16165813%、8/9方向一致。相同9位的链内模型Spearman −0.0833333333、MAE 0.5037411561 Å。7/9位的两组三重复RMSF范围完全分开，仅作为重复间一致性的描述，未作显著性检验；误差线单位为三重复均值差的标准误。数值可核对同目录`independent_numeric_audit.json`。

## 主张和可说到的程度

1. 可以说模型从相近静态复合物结构识别了整段肽的主链动态差异，并预测了未替换位置的响应。输入静态坐标并非完全相同。实际输入按MHC前180个Cα对齐后，肽10个Cα RMSD为0.605 Å、MHC对应RMSD为0.417 Å，不写成“同一几何输入”。
2. 已在最终整合前撤回本例的链内对照段落。缓存来源和缩放未见错误，但链内模型对这一短肽的绝对RMSF严重偏高，差分优势不足以干净归因于伙伴链利用。保留本例完整结构模型对全10位和未替换9位的直接预测证据；详见`intrachain_control_validity_private_audit.md`。
3. A5/G7/V8的MD下降幅度分别为0.447/0.801/0.477 Å，模型为0.206/0.342/0.167 Å。保留幅度低估一句，使相符的变化位置与实际幅值估计清楚对应。
4. 原始研究中的亲和力3.0 μM与743±18 pM属于已发表背景；按中心值比为4037.7，正文写约4,000倍。它用于说明此对照具有识别差异，不把本模型RMSF当作亲和力预测，也不建立“变硬导致亲和力增强”的关系。
5. 原文已通过结构、热力学与MD提出直接/间接静电网络解释。本稿不把此机制当成新发现，不称D6完全不接触TCR，也不把其它位置的响应全部称为远程变构。
6. 本例侧链未变肽位点只有5个χ熵有效位置，三重复差异不足以支持强侧链故事。摘要、引言、讨论与结论统一将KRAS实例限定为主链响应；侧链模型证据由原稿泛素与占据验证承担。无需将弱侧链结果强行画入正文。
7. 已确认主模型第0折实际训练2430条：ATLAS 1866、DynaRepo 564、ITrace 0。不能使用原普通体系划分下包含其它ITrace训练记录的模型分数。原strict第二模型可作为源数据平行复测，不替换主文模型。
