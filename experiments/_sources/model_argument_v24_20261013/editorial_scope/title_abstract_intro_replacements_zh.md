# v24标题、摘要和引言替换建议

本文件是只读v23后的编辑建议，不是已生成的新稿。依据为现有冻结预测与已经核实的文献；83条记录的新预测驱动连续占据评价尚待计算，下面的可用正文不预写该实验的结果。原文定位采用v23的P编号，根代理可在实际合稿时调整编号。

## 模型主张及文章主线

全文主张应是：**FlexPPI从共同的静态主链几何输入联合估计逐残基RMSF与固定χ角区间下的联合状态熵，在同集合对照中检验几何编码、完整邻域及残基类型以外的信息，并用MD分布解释预测读数的含义。**网络的具体输出为两项目标的均值与残差方差参数。主结果验证均值预测，方差头服务于异方差回归；MD角度密度、状态频率及F*用于对照解释同一位置的读数。

结果主线应与这个主张一一对应：整体对照回答几何编码是否有用；Full/Intra回答完整输入环境是否有用；类型内评价回答Hχ是否超出氨基酸平均差异；外部队列和结构病例回答模型读数可在哪些具体条件下迁移与定位；预测与MD分布的对应评价回答模型给出的高低值在实际取向分布中意味着什么。角区间敏感性、时间窗口与采样一致性是这些评价的定义和统计口径，集中放在方法或补充说明，不另列为贡献。

现有参考轨迹中反向RMSF/Hχ组合的存在证明两个目标包含不同信息；组合召回15.8%/16.5%则是当前模型能力的实测结果。标题摘要可强调联合读数的价值，不能把“参考组合存在”换成“模型已准确检索这些组合”。新83条实验的正文位置应服务于最后一个能力问题，待结果就绪后再根据实际方法与数值写入。

## 摘要P2：可直接替换

主链位置波动与侧链取向分布提供不同的局部动态信息，需要在同一结构上联合估计。我们提出FlexPPI，以氨基酸类型及N、Cα和C坐标为输入，通过残基局部框架与不变点注意力编码链内和链间几何，联合预测逐残基均方根波动（RMSF）与固定χ角区间下的联合状态熵（Hχ）。在3,063条记录的五折体系留出评价中，相对静态特征对照，两项平均绝对误差分别降低14.8%和11.3%；类型内比较显示，几何输入提供了残基种类之外的位置差异。在ThermoPCD外部抗体轨迹集合中，完整模型的Hχ误差相对链内模型降低9.4%。KIX与泛素–UBA病例分别验证活动区域排序和同类侧链状态差异，连续角度分布进一步解释泛素的预测读数。FlexPPI在一次推理中提供两种对应到相同残基位置的动态摘要，可用于组织单链及复合物的局部动力学分析。

这里不将方差性能列为摘要贡献，因为现有主评价为均值输出；不把单目标MAE的约0.8%/1.8%差距写成强联合协同。83条轨迹的分箱/F*/Cα分解不再在摘要中作为另一组独立成果串列。新预测驱动验证完成后，如果确实显示模型输出与连续占据摘要有清晰对应，可以用其一个具体结果替换病例解释句，不能只把“203条轨迹分析完成”当成模型成绩。

## 引言：建议将原P5–11收为五段

**第一段：任务需求与两个目标。**

蛋白质的局部构象变化影响分子识别、催化和功能调节。腺苷酸激酶的多时间尺度运动与催化过程相关，钙调蛋白的侧链运动也参与分子识别中的构象熵变化[25,26]。主链位置散布与侧链取向覆盖提供了不同信息：均方根波动（RMSF）描述对齐后Cα位置围绕其均值的波动幅度；侧链联合状态熵（Hχ）依据多个χ角在指定区间内共同出现的频率，描述取向组合的多样性。长时间模拟显示，即使紧密堆积的侧链也可访问多个取向，联合状态占据能够表征这种局部多样性[32]。在相同残基位置提供这两类读数，有助于同时观察主链活动范围与侧链状态差异。

**第二段：相关方法与本工作的任务位置。**

已有方法从不同输入估计蛋白质动态。弹性网络方法由残基间连接描述集体涨落，ProDy提供相应的模型与分析工具[3]；PEGASUS从序列估计MD派生柔性指标，Flexpert结合序列与结构预测RMSF并用于柔性设计，BackFlip系列利用几何表示学习结构波动与运动耦合[4–6,9]。RMSF-net结合原子结构和冷冻电镜密度信息，AlphaFlow生成构象集合，PLANET-MD从序列及可选结构表示预测RMSF、动态相关和结构异质性[10,11,31]。本文聚焦一个具体任务：从静态主链几何同时估计主链波动与侧链多角联合状态占据，使两种摘要能够对应到同一输入结构。

**第三段：需要模型解决的两个问题。**

联合预测需要区分氨基酸类型先验与局部几何环境。不同残基具有不同的侧链角数和理论状态范围，类型平均值能够解释部分整体排序；模型还需要判断同一种氨基酸在不同位置的状态差异。复合物中的局部环境同时包括链内堆积和邻近伙伴接触，因此输入表示也需要兼容独立链与完整多链结构。几何学习在蛋白界面预测中展示了三维邻域的预测价值[14,15]。本文据此以残基距离、相对方向和局部主链朝向描述空间环境，并通过类型内及Full/Intra对照检验这些信息的作用。

**第四段：模型设计如何对应上述问题。**

FlexPPI以N、Cα和C构建每个残基的局部坐标框架，通过不变点注意力共同聚合残基、残基对和三维点信息[7,13]。同一编码器处理输入中的全部有效链，两个读出头分别生成RMSF与Hχ的均值和残差尺度。局部坐标使邻域方向可以与残基主链朝向共同表示，完整结构输入使链内及链间接触在同一几何框架中参与计算。模型采用联合训练作为默认方案，在一次推理中给出对应到相同残基位置的两个动态摘要。

**第五段：能力如何被检验。**

我们整合ATLAS、DynaRepo与ITrace的轨迹标签，在五折体系留出评价中比较完整模型、链内模型、静态特征与类型均值对照[1,2,21]。整体及类型内成绩检验几何输入和局部环境的预测信息，公开权重比较确定其RMSF性能位置；ThermoPCD外部队列进一步考察另一轨迹来源中的幅值与排序。KIX和泛素–UBA病例分别对照活动区域定位与同类型侧链差异，并利用泛素的连续角度占据解释联合读数。数据划分、全组成链家族评价及具体计分口径在方法和补充材料中给出。

新83条模型驱动连续占据评价完成后，第五段可增加一句具体评价目的或结果范围；现阶段不写“模型恢复局部自由能形态”或“83条记录证明景观预测有效”。当前纯参考驱动的中位误差病例选择不承担这一新增能力验证。
