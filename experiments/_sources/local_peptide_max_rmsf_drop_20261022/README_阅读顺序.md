# 阅读顺序

先读《任一肽位点RMSF降幅筛选_完整结果_20261022.md》，其中包含全部7个TCR背景与两个直接SPR面板的结果和解释。图件位于result_figures：max_drop_overview比较前30个候选的筛选收益，max_drop_all_contexts显示全部1197个候选，两个图都提供英文PDF、SVG和PNG。

如果要检查具体候选，打开functional_screening/all_candidate_scores.csv；如果要看每个位点的母本和突变体曲线，打开functional_screening/all_peptide_residue_profiles.csv。直接SPR的逐候选主结果在direct_affinity/primary_26_single_mutants_ranked.csv，完整来源和敏感性见同目录其他CSV。这里保存的是使用原模型预测重新计算的新指标，没有再次训练或生成新模型预测，也没有修改稿件。

常用英文列名的含义如下：panel_id是TCR实验背景，candidate_id是候选编号，mutation是替换（例如N1W表示肽第1位N换成W），mutation_position是发生替换的位置；functional_response是最高测试剂量下归一化4-1BB细胞响应，is_hit表示是否达到0.3；parent_rmsf_A和mutant_rmsf_A分别是母本和突变体预测RMSF，单位Å；rmsf_drop_A是母本减突变体，正值表示预测运动变小；max_rmsf_drop_A取9个位点中最大的下降，max_drop_position记录该位点，second_largest_drop_A为第二大的下降，仅作稳定性诊断。expected_hits是该筛选规则命中数，random_expected_hits是同数量随机抽样的预期命中数，mutation_position_matched_random_hits保留所选突变位置的数量分配后、随机选择替换氨基酸的预期命中数。并列分数按随机顺序计算期望，因此少数方法的命中数可以有小数。

protocol.json记录新分数效用计算前确定的规则；independent_functional_audit.json和direct_affinity/independent_numeric_verification.json记录独立数值复核；delivery_audit.json绑定最终报告、源表及图件的SHA256。原始模型预测仍保存在相邻的local_multimode_screening_20261022和local_antigen_screening_20261021目录，新包提供逐位点完整读数及原始文件哈希，无需重复保存相同模型与预测文件。
