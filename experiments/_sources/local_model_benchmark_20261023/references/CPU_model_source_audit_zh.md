## 下载与执行优先级

本机优先验证 DynaProt-M、已部署 BackFlip、已有 PLANET full/seq 与 FastProtFlex/RMSF-net PDB；Flexpert 两种模态均可尝试，但先单短链测内存再扩队列；PEGASUS 全版留作内存验证后分批。所有推理串行或受内存约束调度，不能同时加载多个 pLM。BioEmu、AlphaFlow、BBFlow等需大量抽样的生成模型，在此CPU条件下不能以零星作者预计算结果充当本轮真实推理横评。

本机只读盘点时，`E:/Project/FlexPPI/baselines/` 仅 Dockerfile；真正缓存位于 `E:/Project/protein_flexibility_models/{hf_cache,torch_cache}` 与 `E:/Project/FlexPPI_baselines/model_cache/`。torch cache 只有 ESM2 t33 650M 与 contact head，不能替代 PEGASUS 要求的 t36 3B。初始未见 Flexpert、DynaProt、PEGASUS 权重，此后由根任务安装的不纳入本次初始盘点结论。

## 横评表与图必须保留的语义

所有以上模型都没有直接预测本文定义的侧链联合状态熵 Hχ。只能在共同的 RMSF 指标上扩充外部方法对照，不能把 Phi/Psi 标准差、SHP、归一化柔性或生成温度当作 Hχ 替代。原始幅值预测器与归一化预测器分别给出可比较指标；缺少可定义幅值时记不适用。冻结公开权重与本文五折重训练不是同一种训练协议，ATLAS训练交叠须显式审计；不同成功样本数应同时报告共同集与coverage，不能按模型各自成功子集直接排名。

官方接口由已安装 GitHub connector 读取，网页路由使用 agent-reach Exa/Jina；Exa后期达到免费速率上限、Jina超时，原论文改用出版方/作者原始PDF核验。未使用二手博客作为模型能力证据。
