# MEL5 / α24β17：全蛋白复算

已复算3HG1与4JFF各3条200 ns轨迹的全部蛋白残基，分别为824与828个位点；保存帧为1001或1003帧，全部保留。使用生成ITrace缓存的原始双精度逐链Cα独立配准及固定120°联合侧链状态熵。所有有效位点的三重复均值与样本方差均通过绝对误差3×10⁻⁶核对，实际最大均值误差4.49×10⁻⁷、最大方差误差2.09×10⁻⁷。12个原始拓扑/轨迹文件读取前后哈希不变。没有新增MD、训练、接触分析或细箱角度分析。

全界面45/32个同氨基酸位点的主链/侧链变化ρ=0.409/0.514，零变化误差收益17.0%/13.7%。拆开区域后，这个双输出结果来自不同部分的互补：TCR界面主链15个位点ρ=0.639、收益42.4%，CDR3的14个位点主链ρ=0.938、收益44.0%，其中9个MD主链变化超过两倍重复标准误、方向全部正确；但TCR界面侧链ρ=−0.467、收益−33.1%，CDR3侧链同样没有正收益。不能将主链的强结果延伸成TCR侧链也准确。

自然位置的MHC+肽界面侧链则较强：23个位点变化ρ=0.755、收益24.8%，其中8个位点的平均变化超过两倍重复标准误，7个方向预测正确。单看MHC界面18个位点，ρ=0.705、收益23.4%；整个10肽的7个有效熵位点ρ=0.786、收益28.9%，但没有一个肽熵变化超过两倍重复标准误。MHC侧链占全界面熵有效位点的56.3%，提供全界面秩协变分子的85.2%；TCR侧链贡献为负。因此，自然MHC/肽位置上的侧链结果并非少量跨TCR匹配的产物。

一个数值与重复均较清楚的MHC位点是K68：MD联合熵由3.2816降至3.0465 nats，变化−0.2350；模型由3.0166降至2.7692，变化−0.2474。三条工程TCR轨迹的K68熵均低于三条WT轨迹，但模型的两个绝对值仍比MD低约0.27 nats。R65的下降方向也被模型识别，且三重复范围分开，但MD下降1.4816、模型仅下降0.3825，幅度偏小。Q72变化量较接近（MD−0.4649、模型−0.4174），但三重复范围重叠。MHC K66、Y159的熵增加被明显低估，因此不能只挑K68作整体证据。

这组对比具有真实工程亲和增强的功能背景，若原文的MHC接触增强能与这些位点对应，它比单纯比较不同TCR更容易形成完整论证：模型捕捉到工程后TCR识别环的主链约束，以及MHC接触面侧链状态重排。现阶段能支持的是两种读数在不同作用区域各有可靠信息；不能宣称每个区域的两个输出均可靠，也不能据此定量预测亲和力。MHC+肽主链变化的误差收益为−28.7%，但其实际平均绝对变化仅0.077 Å；TCR侧链预测差则是需要保留的实质限制。暂不建议把整个复合物压成一个漂亮的双相关图，而应分别画完整CDR3主链与完整MHC接触面侧链，避免把两个区域混合后制造统一准确性的印象。
