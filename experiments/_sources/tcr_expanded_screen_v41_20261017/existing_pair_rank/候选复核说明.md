# TCR–pMHC 变化实例的扩展筛查

已对原251个生物学候选对的主链波动与侧链联合熵做多区域联合筛查。另检视允许末端构建体差异的新313对核心范围指标，旧、新配对并集为343对；本目录的多区域重算脚本对应原251对。排序同时考虑变化排序相关、变化量误差、相对于“全部预测不变”的误差收益、MD平均变化幅度，以及三条重复轨迹所给出的变化噪声。没有把氨基酸替换位点的侧链熵差放入主要筛选指标；同一肽的替换前后，主要指标仅比较氨基酸相同的位置。除原有肽、CDR3、TCR界面、全界面、MHC槽等范围，还保留预先统一定义的CDR1/2/3 α/β环及MHC两条螺旋分区。所有结果与完整位点数据均保存，不据此直接修改论文。

原始251对中，SB27/SB47仍然是“同一条肽的整体变化”最均衡的一对。扩展到允许末端构建体差异的配对后，新增JM22识别流感M1 F5L的1OGA/5HHM尤其值得优先复算：这是同一TCR可变区和相同MHC槽面对一个单点抗原替换，排除F5L替换位点后，剩余8个主链位点和6个侧链位点仍有双指标收益，比较对象比跨不同TCR的少量同氨基酸CDR位置更自然。7L1D/7RRG则以更完整的43/32个界面位点支持主链和侧链变化，范围比仅看单个Q7更宽；其是否能形成比SB27/SB47更有说服力的实例，取决于重复轨迹与既有功能实验是否支持同一个解释。

1OGA/5HHM原始文献DOI为10.1038/NI942和10.1073/pnas.1603106113。7L1D/7RRG为10.1038/s41591-022-01786-3。2VLK/2VLR为10.1016/J.IMMUNI.2007.12.018，5ISZ为10.1038/nsmb.3383。3HG1为10.1074/jbc.M109.022509，4JFF为10.1074/jbc.M113.464560。6VQO为10.1038/s41467-020-16755-y，7RM4为10.1016/j.jbc.2022.101684。5D2L/5D2N为10.1074/jbc.M115.691311。以上DOI来自已有ITrace/RCSB元数据；具体功能叙述仍由原文核查任务确认。

3QDG/4JFF的TCR界面11/6点也有很好的双读数变化（ρ=0.700/0.771，收益26.6%/39.7%），但前者是DMF5，后者是MEL5衍生的α24β17，不是同一TCR的工程前后对比，不能写成“亲和成熟前后”。它可作为不同TCR识别相同MART1的次级候选。6BJ3/6BJ8虽有Pep20恢复信号的漂亮功能背景，但相同氨基酸位点的肽、CDR3及TCR界面结果大都没有收益，当前不适合作为模型解释功能变化的实例；全肽熵收益主要受替换位点的化学类型改变驱动。

新增9RUP/9RXM的TCR可变域154/134个不变氨基酸位点也显示双指标收益（ρ=0.430/0.325，收益23.2%/12.6%，噪声之外72/51个位点），但题名分别为TCRpub/pMHC二聚体与TCRpriv/pMHC，寡聚状态与构建体差异需要先核实。新增5TIL/6G9Q的全肽ρ=0.767/0.750，但主链收益仅6.9%，且病毒肽与自体肽有4个替换；优先级低于单点M1 F5L。

“三重复噪声之外”在本筛查中指平均MD差值的绝对值超过两倍sqrt((方差a+方差b)/3)，仅用于描述性筛选，不是正式显著性检验。不同区域上的候选比较属于发现阶段，不能把最好的局部区域统计当成整个复合物的性能。最终图应显示预先说明范围内的全部位点，并保留预测差的位点。
