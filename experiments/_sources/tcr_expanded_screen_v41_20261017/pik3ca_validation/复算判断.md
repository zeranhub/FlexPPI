# PIK3CA 21LT2-2 / 0606T1-2：全蛋白复算

已复算7L1D与7RRG各3条200 ns轨迹的全部蛋白残基，分别为816与803个位点，每条轨迹1001帧。使用生成ITrace缓存的原始双精度逐链Cα独立配准及固定120°联合侧链状态熵，所有有效位点的三重复均值与样本方差均通过绝对误差3×10⁻⁶核对；实际最大均值误差3.88×10⁻⁷，最大方差误差3.50×10⁻⁷。12个原始拓扑/轨迹文件在读取前后哈希不变。所有逐位结果、三条重复及模型预测已输出。

全界面43个同氨基酸主链位点的变化ρ=0.679、零变化误差收益26.4%；32个侧链位点ρ=0.670、收益17.8%。这个结果并非完全由跨不同TCR的少数匹配位点支撑：去掉TCR，仅保留MHC与肽的自然位置，33/26个位点仍有ρ=0.545/0.724、收益5.4%/15.9%。其中MHC界面26/21个位点ρ=0.684/0.683，收益9.3%/15.4%。但主链误差改善的90.6%来自10个TCR界面匹配位点，不能将26.4%的整体主链收益全部归给相同pMHC环境的预测。

侧链变化中，MHC占全界面有效位点的65.6%，提供全界面秩协变分子的69.7%，故整体侧链相关主要由可自然逐位置比较的MHC贡献。MHC+肽的26个侧链位点中有4个平均MD差值超过两倍重复标准误，3个方向被模型预测正确；三重复不确定性仍然较大。例如MHC R65的平均熵下降0.851 nats，但标准误为0.473，不能把该位点写成稳定的大幅熵下降。Q72三条后状态轨迹的熵均低于前三条，MD平均下降0.662 nats，模型下降0.177 nats，方向一致而幅度明显不足。

整个9肽的主链和侧链变化相关均为0.600，收益13.5%/14.6%，其中只有2个主链位点和1个侧链位点的变化超过两倍重复标准误。CDR3虽有主链ρ=0.806、侧链ρ=0.771，但侧链误差比预测不变更大12.3%，且两个输出的CDR3变化均没有超过两倍重复标准误的位点。因此，本例适合说明“不同TCR环境伴随MHC/肽界面侧链动态重排，模型有一定分辨能力”，暂不适合写成“主链和侧链均在整个界面上准确再现”，也没有显示出明确超过SB27/SB47的重复轨迹支持。

predefined_region_change_metrics.csv包含逐区域的全部统计。interface_component_decomposition.csv将全界面拆为MHC、肽与TCR，列出误差改善、MD变化幅度及全局秩协变贡献。recomputed_pair_all_aligned_positions.csv保留完整对齐位点及每条重复的数值；all_interface_per_position_replica_robustness.csv含三条后状态均高于/低于三条前状态的严格范围标记。跨TCR的同氨基酸配对沿用原筛查的序列对齐，MHC与相同肽的自然逐位置比较单独列出。raw_trajectory_audit.json记录全部源文件哈希、帧数及每种读数的最大核对误差。
