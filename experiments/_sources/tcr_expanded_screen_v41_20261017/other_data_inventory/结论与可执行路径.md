# 本地新增TCR–pMHC资料核查

当前已经完整落地并能立即进行同一模型比较的新资料，是Chen等Science2026的TCR156 WT/S32M系列。TCR识别PAP九肽TLMSAMTNL/HLA-A*02:01；实验结构9NMU与9NMX，MD位于E:/data/CatchBond/WT/WT与E:/data/CatchBond/S32M/S32M。每状态有10条独立DCD，逐帧间隔按作者README为10ns。作者明确披露水氧Lennard–Jones半径参数赋值问题，并认为不影响条件比较和主要结论。本轮记录这一来源条件，没有把它包装成统一benchmark。准备后的模拟构建体仅含MHC1–181、九肽、TCRα108位与TCRβ110位，共408位，不包含MHCα3和β2M。

20条轨迹均按零基帧7:110取103个保存帧。原始DCD时间元数据的dt约0.001ps，与README不符，分析以明确帧索引为准，原DCD时间和README名义时间分别保存。全原子PDB复制到canonical_topology后只做His等名称及IleCD1别名校正，保持所有原子顺序和坐标；在索引层选择蛋白。逐链Cα拟合后的RMSF，与训练原版标签函数交叉核查，最大差5.76×10^-7 Å；Pro使用两χ的联合三态分箱，Ala/Gly的Hχ为空值。全部408位、20重复的8160行数据与原始SHA均已保留，未训练或新跑MD。

同一联合模型对实验匹配结构与模拟准备结构的两套推理，给出基本一致的结论：CatchBond目前没有比SB27/SB47更强。实验匹配结构在407个氨基酸未改变位点的ΔRMSF相关为0.0221，变化MAE0.04289 Å，劣于全部预测不变的0.02721 Å；343个有效侧链位点ΔHχ相关为−0.0199，MAE0.13846nats，零变化0.13472。肽九位ΔRMSF相关−0.0167，MAE0.02880 Å，零变化0.02744 Å；八个有效Hχ位点相关−0.2619，MAE0.08041nats，零变化0.07434。两套输入间的ΔRMSF平均差仅0.00174 Å、ΔHχ平均差0.000656nats，不能把失败归因于实验/准备结构选择。

S4的RMSF变化数值局部吻合：MD−0.03088 Å，模型−0.03576 Å。但10条独立重复形成的Welch95%区间为[−0.06392,0.00216] Å，尚未排除零；S4的Hχ变化MD−0.14633nats，模型仅−0.00638nats，MD区间也跨零。M6变化方向相同，但模型低估，且10重复区间仍跨零。S32变为Met本身增加了可转动χ角数，不能用该位点的熵增加证明相同化学基团受到环境调节。CDR1α、CDR3α与CDR3β按预定作者编号范围保留全部位置，详见regional_change_metrics.csv，不再从中筛单个好点作强机制论证。

除CatchBond外，当前ATLAS1929/DynaRepo890记录的完整RCSB蛋白注释中仅3KXF包含TCR，其他免疫复合物多为pMHC/CD4/CD8、超抗原或抗体。ThermoPCD本地1051标题的TCR/HLA/MHC关键词检索无命中，不能将它理解成穷尽全文后证明不存在。公开DynaTPH256个复合物里有59个PDB不在ITrace，已有肽平均RMSF小表，但旧README中的完整轨迹审稿受限状态需要在线重查；当前本地没有完整轨迹，也没有逐重复Hχ。Knapp2019 A6归档仍为未校验的partial文件，其准备构建体缺失β链三段内部片段；1G4/JM22/LC13完整轨迹尚未落地，只保留准确Figshare清单。

3KXF从旧ITrace244集排除的原因是与DynaRepo A005I的PDB精确重复，而非MD损坏。当前all-chain-family fold0把A005I列为测试集，未放入训练，所以相同fold0模型可以用于独立重建的ITrace3KXF输入/标签。它增加的是同PDB的第二套MD协议，不能作为新的独立PDB。其家族Full现有缓存A005I.npz，以及A0053.npz/A0055.npz，已从hit-gpu只读取回本目录。

跨来源pMHC对照已完成轻筛。A0053=3H7B是没有TCR的Tel1p–MHC，与ITrace3H9S的肽与MHC观察序列完全一致，但模型变化预测不理想：九肽ΔRMSF相关0.233，MAE0.37348 Å，零变化0.14082 Å。A0055=3HAE抗体结合的NYESO-1 pMHC与2BNQ等TCR结合态也未形成稳定优势。DynaRepoSB27(A005I)与ITraceSB47(4JRY)的13肽ΔRMSF仍较好，相关0.8901、MAE0.08086 Å，零变化0.18200 Å，可作为原SB27/SB47主链差异的跨MD协议辅助复核；整体Hχ相关−0.0826，不能称为两个输出均改善的新独立实例。

关键产物位于同级catchbond_validation目录：all408_MD_model_changes_both_inputs.csv保留全部位点；regional_change_metrics.csv对照零变化基线；regional_mean_change_uncertainty.csv以每条独立轨迹为统计单位；experimental_vs_prepared_input_sensitivity.csv检查输入敏感性；MD_recomputation_audit.json、model_MD_comparison_audit.json和independent_numerical_QA.json记录来源与计算检查。现有证据不支持用CatchBond替换SB27/SB47主文实例。
