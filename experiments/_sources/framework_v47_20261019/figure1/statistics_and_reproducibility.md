# Figure 1: statistics and reproducibility

This figure explains the implemented model. Its framework and operation glyphs are conceptual; no new training, inference, molecular dynamics, numerical calibration, hypothesis test or selection of accurate sites was performed for this revision.

Panel a retains all 840 positions of the original 4g9f example across chains A/B/C/D/E, of lengths 276/100/10/204/250. The source table has 1,680 target rows: 840 RMSF and 840 Hχ rows, with valid counts of 840 and 734. All valid raw predictions are retained. Fine native paths display the raw predictions; thick paths display centred ±5-position means within the same chain, using valid values only. An invalid central Hχ position stays absent. These are local means, with one weight per valid neighbouring position, rather than averages across chains; chain boundaries are not connected. The window shrinks at chain ends. This smoothing is not a confidence interval. The full original fixed axes are retained, RMSF 0–4 Å on the left and Hχ 0–4.1 nats on the right, without recalibration or truncating valid predictions. No statistical uncertainty interval or significance test is shown. The complete raw data, original masks and local means are archived in source_archive/curve_data_all_840.csv and curve_local_means.csv. The current native Draw.io document preserves all 224 original curve objects and their complete vertex geometry exactly, including the original path segmentation. Independent recomputation of every local mean matches the archived means exactly.

The assembly input, prediction-coloured assembly and chain-D ribbon are rendered through one PyMOL secondary-structure and material pipeline in assets3d. Actual coordinates determine secondary structure using DSS; regular beta arrows and helices replace the former forced-tube chain-D rendering. The chain-D assignment contains 80 sheet and 6 helix Cα positions among all 204 residues. Atom coordinates are unchanged, as verified from the source PDB and saved molecular sessions. The assembly and local-chain view use the same original chain palette, with D green (#1B7837); the same original gold highlights D166 in the local view. The prediction-coloured structure retains every one of the 840 original RMSF values and their exact original RGB colours, including the original five-anchor continuous interpolation over 0–4 Å. The legend comprises the original 64 sampled rectangles along that continuous colour map; these are display samples, not 64 discrete RMSF categories. The exact original 64 vector rectangles and colour values are preserved. The rendering has constant cartoon thickness, not an RMSF putty-radius encoding. Per-residue values/colours, camera, material and source-coordinate hashes are documented in assets3d/all_840_preserved_RGB_audit.json and its associated receipts.

Panel b displays the complete 204-residue chain D. The two short local coordinate systems are anchored at true D:Gln67 and D:Met166 Cα positions, with orientations obtained from their actual N–Cα–C atom coordinates. The labels i and j are graphical residue indices. The magnified D165–D167 peptide backbone is the original true 12-atom N/Cα/C/O sphere-and-stick render, retained byte-for-byte with the coordinate and axis projection receipt. Its frame origin is D166 Cα; x is normalised C−Cα, y is the normalised part of N−Cα perpendicular to x, and z=x×y. The local axes and global-axis directions are projected using their corresponding actual cameras; the global triad is a direction reference placed in white space, not a claim that a displayed global origin equals a centroid. No idealised atom position, bond, secondary structure or predicted coordinate is introduced.

Panel c's feature bars, pair matrix and point pair are nonquantitative operation glyphs. They do not display measured attention scores or selected atom positions. The learned Q/K points are latent geometric features. The implemented score combines scaled scalar similarity, pair-derived bias and a nonnegative weighted squared distance of Q/K points after transformation to one common global coordinate system. A masked softmax gives one set of weights for scalar-value, pair and global-V-point aggregation. Point results return to the query residue's fixed local frame; local xyz and point norms join the other outputs before the merged linear projection and residual update. Frames and pair representations remain fixed between blocks, while residue representations update. Four blocks and eight heads match the actual five-fold model configurations. The native overview preserves both residual additions and the shared LayerNorm–Linear–SiLU–Linear readout. One shared readout produces a mean and a log variance for each of the two targets.

Panel d preserves all three original MD snapshot images byte-for-byte. It does not claim that all datasets share the same simulation duration. Replicates or trajectory windows supply observable means and their known observation variance. The Gaussian NLL compares the predicted mean with the observed mean using total variance exp(predicted log variance) + max(observed variance, 0). Observed variance is supplied to the loss; it is not a regression target. The formula inside the loss card uses σ² for the predicted residual variance and v(MD) for the observation variance.

The master is 183 × 144.259 mm. Word inserts it at 167.64 mm wide, scaling by 0.9161. All visible text is English. The smallest PDF text is 9.056 pt at master size, or 8.296 pt after Word insertion. Every PDF word bounding box was checked against the physical page. Editable vector text, module shapes, paths, coordinate arrows and the 64-cell legend are preserved in PDF/SVG/Draw.io; genuine molecular images remain embedded raster renders. The PNG preview is rendered from the vector PDF at 450 dpi. Numerical paths, source files and current-output hashes are recorded in render_audit.json.

For a self-contained rebuild of the current figure, run build_b_prototype.py then build_framework_native.py. Both read locally archived source files and the prepared assets3d images; no old checkout is needed when these archives are present. The established bundled Python runtime supplies numpy, pypdf, Pillow and the plot runtime; Draw.io Desktop performs native vector export, Poppler renders the PDF, and pdftotext produces font/bounding-box QA. PyMOL is needed only for optional molecular-image regeneration, using the scripts and source files in assets3d. Current protein source archives and sessions are stored alongside the figure. The original native base file is source_archive/original_framework_v13.drawio. README.md identifies current masters and distinguishes working prototypes.
