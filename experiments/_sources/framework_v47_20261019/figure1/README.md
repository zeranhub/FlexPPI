The molecular renderings in `assets3d` share one secondary-structure assignment and material pipeline. Other prior candidates, `chain_d_ribbon.png`, `fig1b_prototype.*` and the raw previews are working assets, not the current Figure 1 master.

To rebuild the final native figure, run `build_b_prototype.py` and then `build_framework_native.py` using the established bundled Python runtime. The source Draw.io document and all images are stored locally in this folder; the scripts use archived files when they exist. Draw.io Desktop is required for native vector export; PyMOL is required only to regenerate genuine molecular renders. The scripts in `assets3d` and their receipts document this optional rendering step. No new prediction, training or molecular dynamics is needed.
