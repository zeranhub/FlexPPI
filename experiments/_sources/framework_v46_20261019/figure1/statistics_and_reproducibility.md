# Figure 1: data and scientific reproducibility

This is a model framework figure. Panels b–d explain the audited model operations and are not new experimental measurements. No training, molecular dynamics, inference, calibration, hypothesis test or selection of high-performing predictions was performed for this redraw.

Panel a retains the complete original 4g9f example: 840 residue positions across chains A/B/C/D/E, with chain lengths 276/100/10/204/250. The source table has 1,680 target rows, 840 for RMSF and 840 for Hχ; the valid counts are respectively 840 and 734. Every valid prediction is plotted as a fine line. Thick lines use the original centred ±5-position mean within the same chain, using valid target positions only. An invalid central Hχ position stays absent. Lines do not connect across chains. The full original ranges are retained: RMSF 0–4 Å and Hχ 0–4.1 nats, with separate left and right axes. Raw values are not normalised or calibrated; only the right-axis affine map is used to overlay the two original unit scales. A mean-window smooth is not an uncertainty interval. The original numerical values and precomputed local means are preserved byte-for-byte in source_archive/curve_data_all_840.csv and curve_local_means.csv. Independent recomputation of all local means matches exactly. No significance test or error interval is shown.

Input and predicted-RMSF structure renderings are reused from the source Figure 1 native objects, without repainting molecular geometry or prediction colours. The original 64 native colourbar cells and 0–4 Å mapping are archived as rmsf_original_scale.json and reproduced as native vector rectangles. The whole-chain locator retains all 204 residues of chain D. Its display opacity is 0.82 to subordinate the locator to the atomic construction. The zoomed frame uses actual N, Cα and C coordinates of residue D:Met166. The other displayed frame is D:Gln67. Both frames and their projected directions come from the source atomic/projection receipts. The N–Cα–C planar zoom is drawn in that exact local frame at 7 display-mm per Å; no idealised bond angle or length is substituted. Frame origins are Cα; x = normalised C−Cα; y = the normalised component of N−Cα perpendicular to x; z = x×y. The depicted learned point q is schematic and is not an atom, an inferred coordinate or an experimentally observed point.

Panel c displays the implemented attention logic: scaled scalar similarity plus pair bias minus a nonnegative weighted squared distance of Q/K points after their fixed-frame transform to global coordinates. The same attention weights aggregate scalar values, pair representations and global V points. Aggregated points return to the query-residue frame; local xyz components and norms enter the merged projection. The micro-matrices, feature bars and point coordinates are conceptual glyphs, not numerical attention measurements. Residue frames and pair representations do not change between blocks; residue representations do. Four blocks, eight attention heads and the single shared readout MLP match the actual five-fold resolved configurations. Pre-normalisation and the two residual connections per block are retained in code and prose; the simplified overview does not draw an ambiguous residual loop.

Panel d reuses the original three MD snapshot renders. No common simulation duration is implied by these snapshots. The training loss receives the MD summary mean and its known observation variance; the joint readout predicts a mean and log variance for each target. The total variance is exp(predicted log variance) + max(observed variance, 0). The Gaussian NLL compares the prediction mean with the observed mean using this total variance. The MD variance is not a regression target.

All visible figure text is English. The master canvas is exactly 183 × 153 mm. The 167.64-mm Word insertion scales it by 0.9161. The smallest source text is 9.1 pt, corresponding to 8.336 pt in the manuscript. PDF/SVG preserve vector text, lines, geometric constructions and graph elements; the six genuine molecular structure images remain embedded raster images. PNG preview is exported at 450 dpi. Source/output hashes are recorded in render_audit.json and the frozen scientific manifest.

Run draw_framework.py with Python after putting numpy, pandas, matplotlib and Pillow on the import path. The established bundled plot runtime is automatically located relative to this revision folder. The complete output depends only on the archived source files and that runtime.
