# Analysis output schema

- `summary.json`: `metrics[target][method]` contains `mean_ap`, `ap_ci`, `mean_auroc`, `auroc_ci`, `macro_mae`, `mean_spearman`, `n_records`, `n_total_records`, `n_positions`, `prevalence_mean`, `prevalence_min`, `prevalence_max`, `undefined_records`. Targets are `rmsf` and `chi_entropy`; methods are `Full`, `Intra`, `Static`, `AA`. `within_type[method]` gives auxiliary Hchi within-type ranking. `coverage[target]` gives complete plotting ranges and eligibility.
- `per_record_metrics.csv`: one row per record, target and method, including reference threshold, class counts, prevalence, eligibility/reason, AP, AUROC, MAE and Spearman. Original-unit MAE and Spearman reproduce original exports. No undefined row is deleted.
- `record_codes.csv`: every original sample ID/source/fold and integer record code.
- `raw_curves_{target}_{method}.npz`: complete score-tie-group threshold curves concatenated by record. Every array is the same length; `record_code` identifies a segment, `threshold` starts at infinity for its no-selection endpoint, and the remaining arrays are `precision`, `recall`, `fpr`, `tpr`. These raw original thresholds permit exact AP and AUROC reconstruction; no grid interpolation is used to calculate the metrics.
- `macro_pr_curve.csv`: `target`, `method`, `recall`, `precision`, `precision_ci_low`, `precision_ci_high`, `n_records`, `no_skill_precision`. Recall runs from 0 to 1 in 0.01 increments. The stated right-endpoint tie-group rule is used without a precision envelope. The AP annotation is the mean of exact per-record AP, not the numerical area under this 101-point display curve.
- `all_selected_endpoint.csv`: same target/method/recall/precision/CI/count columns, plus endpoint label. Append this original full-selection operating point after the macro display grid: it has recall=1, precision=record-macro positive prevalence, and is verified against every raw curve's last original threshold. The resulting vertical segment at recall=1 contributes no recall increment and does not alter AP. `curve_endpoint_audit.json` records the verification.
- `prediction_reference_{target}.npz`: all original `reference`, `prediction`, `record_code`, `amino_acid`, `fold`, `residue_index` arrays (one entry per valid residue), plus `histogram_mass`, `x_edges`, `y_edges`, `density_axis_scale`, `linthresh`. `histogram_mass[i,j]` maps the ith MD-reference bin and jth Full-prediction bin. It sums to one and gives every record equal total weight. Empty cells have zero mass. RMSF uses symlog axes (`base=10`, `linscale=1`, `linthresh=1` Angstrom); Hchi is linear. RMSF x and y should use identical symlog settings. Both edges are in original physical units, so axis values do not require inverse transformation.
- `reference_binned_trend.csv`: target, original-unit bin edges, `x_mean`, `prediction_mean`, bootstrap `ci_low`, `ci_high`, and `n_positions`, `n_records`, `record_equal_mass`. A bin with zero observations has undefined means and should not be connected to a neighboring trend. All points remain in the density and original-point export. The trend is descriptive conditional mean of untouched predictions, without fitting calibration.
- `within_type_per_record_metrics.csv`: one row per record/type/method, retaining small/one-class types and reason; within-type labels use that type's own MD q90. `within_type_record_macro_metrics.csv` averages eligible types equally within each record. All AA-only valid groups are checked to have exact AP=positive prevalence and AUROC=0.5.
- `input_alignment_audit.json`: exact input SHA256s, assertions of full identity/target/mask/order agreement, reproduction of original metrics, complete exclusions, protocol/script hashes and runtime.

Confidence intervals use source-stratified record bootstrap; all methods share draws. No new training, inference or MD run occurred. The prespecified protocol is saved separately as `PRESPECIFIED_PROTOCOL.md`.
