# v48 图1重绘说明

本轮只改动图1（模型框架图）及其图注，正文、表格、公式、参考文献、批注与其他图均未改动。

## 为什么重画

v45 的图1信息齐全，但视觉上有几处硬伤：五列内容挤在 1–1.5 mm 的间隙里，箭头穿过文字；标题与框内文字几乎全部加粗，字号层级不清；紫/黄/蓝三块填充饱和度过高、边框厚重；b 子图把三组坐标轴和三处残基名直接压在蛋白带状结构上；右侧色条与双纵轴曲线挤在一起，曲线细节在印刷尺寸下糊成一片。

v48 保留原有叙事与全部科学要素（五段式输入→编码→读出→输出、层叠编码器、读出层内部次序、b/c/d 三个解释性子图），重画了绘制体系：

- **统一排版**：Arial，正文标签 8 pt，面板标题 9 pt，面板字母 11.5 pt；全图最小字号 8 pt（按 170 mm 插入宽度 1:1 排版，插入后不缩放）。
- **统一图形语言**：0.6–0.8 pt 细线，圆角 0.8–1.3 mm，浅色填充，无阴影无渐变；箭头统一为细杆+实心小三角；列间留 4 mm 通道并画出流程箭头。
- **统一配色**：标量=蓝、成对=赭、点=紫、编码器=石板灰、读出=青绿，同一语义在全图保持；链条颜色降饱和，避免与 RMSF 色阶争夺注意力。
- **真实结构重渲染**：PyMOL 3.0 光线追踪（ambient 0.5 / direct 0.48 / specular 0.12，dss 自动指派二级结构）。输入结构与预测结构共用同一相机；b 子图 D 链与放大视图共用同一着色体系。
- **b 子图重做**：整链带状结构上只保留 i、j 两处小坐标轴；放大图改为 5 个残基的真实主链球棍（N 蓝、Cα 灰、C 浅灰、O 红），坐标轴按真实帧定义投影后叠加，标签加白描边；旁附变换式 pᵢ = Rᵢqᵢ + tᵢ 与 x/y/z 定义。
- **输出区重做**：结构按全部 840 个残基的折外 RMSF 预测着色（沿用原 840 个 RGB），色条 0–4 Å；下方两条独立面板分别为 RMSF 与 Hχ 的逐位预测（浅色细线）与 11 残基均值（深色线），不再共用一个双纵轴面板。
- **c/d 子图**：保留纵向流程与对应计算步骤，压缩为一个主流程，去掉重复措辞。

## 科学一致性

- 模型结构：4 个共享 IPA 编码块（8 头）、LayerNorm 前置、两处残差相加、Norm+FFN，共享读出 MLP（LayerNorm–Linear–SiLU–Linear）为 RMSF 与 Hχ 分别输出 μ 与 log σ²。
- 几何：局部原点在 Cα，x 轴沿 Cα→C，y 轴由 Cα→N 正交化，z 轴为叉积；帧构造与 `itrace_4g9f.pdb` 坐标逐残基一致。
- 训练目标：v = σ² + v_MD，高斯负对数似然；MD 快照沿用原图真实渲染，未新增 MD、训练或推理。
- 数字：4g9f 840 个残基、5 条链、色条 0–4 Å、Hχ 上限 4.1、11 残基均值窗口，均与原图及正文一致。
