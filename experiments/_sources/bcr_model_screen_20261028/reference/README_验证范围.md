# BCR候选的预定义验证范围

本文件在分析者未查看模型输出时固定文献范围，不预设候选会成功。全部共享残基、完整Fv重轻链、六个经独立编号的CDR和完整抗原输出均须保留；文献局部位点只作预先指定核查，不取代完整结果。数值与完整范围见literature_validation_contract.json，逐位点核查见all_literature_named_NMR_sites.csv。

HyHEL10的主要单点为H:R71A和L:R45A，近似无亲和变化的对照为H:Q3A和L:H34A。后两者不是已经证明“无动态变化”的对照；Q3A由于稳定性不足未继续做动态分析，H:R44A则聚集而不能作真实亲和力阴性。上述变体均没有该论文报告的独立突变晶体；若复用1C08或5AYU骨架只改序列，只能称固定骨架敏感性。

2017论文中游离态NMR明确点名的R71A未替换响应位为H:Q3/V24/T25/S28/S31/W36/T56/S68/D72，共9位；R45A响应位为L:H33/G84/F87/F98及H:E46/V24/T25/S28/S31/W36/D72，共11位。这里H:T56在1C08和5AYU同号为Ser，L:H33同号为Leu，存在AA/编号不一致，两项应标为映射未解决，不能静默改成H57或L34。另有被改变的H71、L45本身，不能用于同型侧链熵比较。全32个游离WT交换位点未从正文得到数值表，不能捏造完整逐位真值。

NMR是游离态毫秒交换，与模型基于MD的RMSF/Hχ并非同一标量、同一时间尺度。论文结合态130nsMD明确给出的主要局部证据是H:I29–H:S74的Cα距离收缩0.38Å，以及L:H41–H:G42距离收缩1.1Å；更紧的堆积本身不等于RMSF或Hχ下降。没有原始轨迹时，只能将模型输出作为定性假设核查，不能宣称已测得定量预测准确率。

FlexHEL的当前PDB对应为6P4A=WT Hy10+rigid抗原、6P4B=4xHy10+flex抗原、6P4C=游离4xFab、6P4D=游离HEL3x。原文Fig5的ID对应与当前结构不符，需用当前序列核实。6P4D的101位是Arg，6P4A/B抗原101位是Asp，不能把6P4D直接当作序列相同的rigid apo。6P4B含两份晶体copy，可作敏感性但不能算独立重复。

FlexHEL发表的三重复MD支持游离抗原73–78环在flex中RMSF增大，不是抗体或复合物的MD真值。侧链网络预定义为未替换的抗体H:W34/I29/Y53、抗原D101/W62，另保留抗原K97与抗体H53骨架联系；四个抗体突变及C76S/C94S不作同型Hχ比较。这些网络来自晶体构象重排，没有侧链熵方向先验。6P4A→6P4B同时改变抗体和抗原，属于状态比较；6P4C→6P4B则可比较同一4x抗体的游离/结合结构。
