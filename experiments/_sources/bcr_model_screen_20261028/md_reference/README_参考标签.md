# 本地可核验的抗体相关动态参考

三个原始NPZ标签均已按项目原始标签函数从本地XTC重新计算并逐值核查，A00EJ与A00KW的Hχ逐值完全一致，三个体系的RMSF差均小于10⁻⁶ Å。A00HE有一位Hχ差0.00013417 nats，方差差0.00004995，已在审计定位并同时保留原始与重算值，未宣称其完全一致。原因尚未确定，离散箱边界敏感性仅为可能性。完整逐残基表为existing_labels_per_residue.csv，链级汇总为chain_label_summaries.csv；原始与重算最大差、文件SHA、编号映射、时间与窗口数见reference_label_audit.json。未运行新MD或修改任何原文件。

A00EJ（6P4B）仅含128残基D链抗原，A00HE（1VFB）仅含128残基C链抗原，不能据此评价Fab识别环；它们也不是严格只改变柔性的配对。A00KW（1MLC）为553残基三链D44.1 Fab–溶菌酶复合物：A轻链210、B重链215、E抗原128；它不是HyHEL-10，且没有配套突变对照。

每项本地只有一份trajectory.xtc。元数据写三重复，不等于本地存在三条独立轨迹。A00EJ/A00HE的五个1000帧窗口属于同一长轨迹，标签方差是窗口差异；A00KW仅一个1000帧窗口，方差为零不表示无动态不确定性。RMSF为逐链拟合后的Cα波动（Å）；Hχ为每个侧链全部χ角三箱联合状态熵（nats），不是NMR弛豫交换、热力学熵或结合能。

这些记录已在训练清单出现，必须由当前完整组成链家族划分选择真正留出检查点后，才能作为模型实际输出的参考。
