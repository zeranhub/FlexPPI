# FlexPPI候选案例图册

这是独立的案例评估文档，使用论文式字体、三线表和每例一张整页多子图大图。既有v49论文为内容来源，不作为待编辑文件，SHA256应保持5f79ddf7d657dc9b782c9fb432e373a1e7c170c1c88d019e528fbf73c366c222。

内容覆盖30个已点名TCR候选系列和KIX、泛素两个已有案例；343个原始发现性配对另附索引。每个候选的介绍包括生物背景、真正的实验对照、已有模型证据、机制推断及具体缺口。弱结果和失败保留。仅有条目元数据的系列明确说明功能机制待核。图中英文，正文中文。

版式为A4纵向，上下15 mm、左右13.5 mm，正文宋体12 pt和Times New Roman，1.2倍行距，段后7 pt。题名黑色18 pt，一级标题黑色14 pt。每例正文与整页图形成相邻页面，图宽183 mm、不拉伸，图注10 pt。页脚仅页码，便于70页以上图册导航。全部表格无底纹、无竖线，保留顶线、表头下线、底线；跨页重复表头。

输出为一个新DOCX，附可复现PNG/SVG/PDF及源数据内部归档。交付前须实际渲染并逐张查看每页PNG，核对32张图嵌入哈希、所有案例/图注/引用覆盖及三线表原生结构。不能把图像或正文中的描述当作已经验证的因果机制。
