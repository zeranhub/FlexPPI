# Figure 2 design precedents

The relevant feature of the consulted model-paper figures is the joint presentation of models, tasks, and dataset-specific results with shared visual encodings. It is not a numeric requirement for a fixed count of panels or symbols.

- [OPUS-PLLM, Genome Biology2026](https://doi.org/10.1186/s13059-026-04109-8), Figure2: method comparisons across several tasks and testing datasets. The published caption supports using task groups and comparator groups in one cohesive figure. Accessed2026-10-18 through official publisher search.
- [Benchmarking deep learning methods for biologically conserved single-cell integration, Genome Biology2025](https://link.springer.com/article/10.1186/s13059-025-03869-z), Figures2/4: dataset-wise comparisons combined with aggregate comparison and compact metric maps. Accessed2026-10-18 through agent-reach/Exa official-publisher text.
- [SpatPPI, Genome Biology2025](https://link.springer.com/article/10.1186/s13059-025-03820-2): geometric protein modelling comparison with dataset-specific performance and model components. The article is an example of relevant comparator organization, not evidence for FlexPPI claims.

Local redesign decision: the previous e/f pair displayed76 residue-type gain values in a large area but added little beyond existing type-MAE conclusions. The replacement adds within-type Hchi ranking, which directly tests position selection beyond amino-acid-type prior, and shows whether the same comparisons hold across the three trajectory sources. The top-row trend comparison reveals where competing predictions differ across the observed MD range. No literature claim is inserted into the manuscript solely to justify its layout.
