本目录复用既有泛素数据，未开展新MD、训练或推理。全部66个有效联合Hχ位点及151个实际定义角均保留；χ1至χ4分别为66、52、23、10个角。264个统一角槽中的113个未定义角仍为缺失，P19、P37、P38的原零联合熵参考和实际角度均保留。

主分析是“联合Hχ读数与每一个χ角的实际MD占据如何对应”。MD主指标为每个角的5°细箱Shannon熵；第二指标为相对投影自由能F*≤1的全部角区总宽度。两者均由0–100 ns的501帧统计，并平均0°、1.25°、2.5°、3.75°四个箱格原点。逐角指标及四原点各自结果已从保存角度重新计算，细箱熵最大差为1.33×10⁻¹⁵，宽度差为0。

同类型控制在每个χ层内分别进行：先从每个位置的联合Hχ预测减去该层同种氨基酸的预测平均值；从该位置的单角MD指标减去同种氨基酸的MD平均值；再对该层全部位置的两列差值计算Spearman相关。它不是把每种氨基酸的相关再平均。单例类型在主分析中保留，其两列差值为0；常数组按相同规则保留，秩并列取平均。仅供核对的排除单例敏感性结果另存，未用于替换主结果。χ1/χ2各有H、M、Y三个单例，χ3有M一个单例，χ4无单例。

同类型控制后的细箱熵相关χ1至χ4依次为0.497505、0.447186、0.524704、0.127273；低F*宽度相关依次为0.195150、0.395550、0.639980、−0.182930。χ4的细箱熵关联很弱、宽度关联为负，完整保留。原值相关也全部保存，包括χ3原值中的负相关。本例只有一个蛋白，四角的位点与类型组成不同，这些结果用于逐角核对占据对应，不用于宣称某个角的预测精度最高，也不提供置信区间或显著性检验。

模型对每个残基输出一个联合Hχ，不输出四个单角熵、宽度或自由能曲线。因此本分析报告关联ρ，不把单角MD值与联合Hχ直接相减当MAE。原MD联合Hχ与单角指标的关联随同提供作描述性参照，并非单角预测精度的上限。另一个备选问题是按残基本身具有1、2、3、4个角分层，评价原联合Hχ预测的MAE及ρ；此结果保存于`joint_prediction_accuracy_by_angle_count.csv`，其“有4个角的残基精度”不是“第4个角预测精度”。

绘图直接读取`figure_statistics.csv`，四行依次为χ1至χ4，字段为`chi_index`、`n`、`rho_entropy_typecentered`、`rho_width_typecentered`，另有两列原值相关。`per_chi_correlations.csv`完整保留预测联合Hχ、真实联合Hχ与两种单角MD指标的原值和同类型控制相关。`all_angle_slots_long.csv`保留264角槽，`defined_angles_long.csv`为151个实际角的长表；其中保存用于统计的同类型差值，便于逐位复算。`per_chi_AA_counts_and_constant_groups.csv`列出每层各类型的个数与常数状态；`definitions_and_handling.json`给出精确定义；`audit.json`记录1,149项检查、原源及产物哈希。运行`analyze_all_chi_associations.py`可重建本目录全部数值结果；脚本优先读取相邻`../source`的四个冻结输入，原始路径仅为备用。`source/analysis_source_manifest.json`保留原路径、SHA256与同一性检查结果。
