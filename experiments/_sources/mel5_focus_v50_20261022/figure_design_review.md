# MEL5 图4：集中到跨界面双动态读数

审阅范围：已检查 v49 的 `fig4_mel5_joint.png`、`source_manifest.json`、`data_audit.json`、全部界面 Hχ 源表及 `trajectory_link/key_findings.json`；只作设计审查，不改模型、不补 MD、不编辑主稿。

**建议采用三 panel，删除原 d，重构 c；不优先采用两 panel。** 全图只讲一个结论：MEL5 亲和成熟伴随对侧 HLA Q72 侧链状态更集中与 βGly54 主链波动降低，模型把两种读数定位到 Q72–βPhe53/βGly54 接触网络。a 给空间位置，b 给完整识别环背景，c 回答该侧链信号在界面中如何突出、是否依赖 TCR 环境。这三项各有不同作用，原 d 只有两项 MD 占据率，单独占一整行不值得。

c 左右建议约 2:1 宽度。全图 183 mm 宽，目标总高约 150–165 mm；c 高 42–48 mm，左侧 23 个短残基标签转 55–65°，右侧两行共享轴并直接写清条件。不要用额外卡片、框、圆角底色或说明段落填版面。对 HLA 与 peptide 的身份，短标签直接加 `p` 前缀或底部细分组条即可，不需独立图例占位。

**两 panel 备选是可行的，但支撑会变弱。** 把 Q72 与 Gly54 的母本/成熟模型绝对数值都整合进 a、保留 b，即可诚实支撑“具体残基网络中的联合解释”；但读者看不到 Q72 在所有界面位置里的相对突出程度，也看不到模型对 TCR 环境的响应。用户明确关注信息含量，现有环境扰动数据有独立论证价值，因此优先三 panel，而不是把 c、d 都删掉。

表达边界只需落实到标签和一句图注，不需要防御性段落：c-right 必须称 `TCR removed; fixed pMHC coordinates`（或等义短语），不能称 apo/free state；它证明的是预测对输入界面环境敏感，不能单凭该计算反推真实溶液的游离态变化。a 的两条虚线表示结构几何接触，不能把它们画成定向传递链。原 d 的 Q72–Gly54 接触占据由 24.4% 至 97.4%、双端氢键同帧占据由 0 至 37.1% 可以精简留在正文支撑网络稳定化，不再单独绘图；三条重复数据及定义在源表和方法保留即可。
