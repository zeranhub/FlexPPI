# KRAS 案例：模型现象与机制叙述独立核查

本核查直接读取原有 Full 第 0 折联合模型对 7OW5、7OW6 的 NPZ 预测文件，取肽链 C 的全部 10 个位置，核对氨基酸、位置编号以及原始均值列，再与旧图源 CSV 的绝对 RMSF 和差值逐项比较。所有数值误差小于 1×10⁻¹⁴ Å。未重新训练、重新预测或运行 MD。全部原文件路径和 SHA-256、10 个绝对值及所有重原子近接触均保存在同目录 `model_phenomena.json`，复算脚本为 `inspect_model_phenomena.py`。

最有解释力的模型现象是有空间选择性的响应。WT 肽的 P6–P10 形成较高波动段，G12D 中该段仍有波动，但幅值下降；P6 和氨基酸未改变的 P7 是下降最大的两个位置，分别从 1.080 变为 0.718 Å、从 1.246 变为 0.904 Å，降幅约 33.6% 和 27.4%。未替换的 A5、V8、G9 与 K10 同样下降，而 N 端 V1–V3 几乎不变：三位的平均值为 0.613 与 0.610 Å。P4–P10 七位全部下降，描述性均值由 1.027 变为 0.803 Å；这些区域均值是用于解释完整曲线的描述汇总，不是新的统计检验或预先注册的分区比较。这个现象适合用来论证模型把突变对应到一片周围主链的动态响应，而非只对被替换氨基酸给出不同数值。

模型输入结构与原文机制可以形成具体的空间对应。读取模型所用初始帧，以两残基任意重原子距离不大于 4.5 Å 定义几何近接触，P4–P9 均接近 TCR，P1–P3 与 P10 在此阈值下没有 TCR 近接触；P10 处于 HLA 口袋的锚定环境，不能把 P4–P10 全部称为“TCR 直接接触区”。G12D 的 D6 羧基 OD2 与 HLA Arg114 NH1 距离为 2.875 Å，Arg114 NH2 与 HLA Asp116 OD2 距离为 2.632 Å；D6 羧基到 TCR 的最近重原子距离为 7.537 Å，说明该输入中新增羧基首先对应肽–HLA 侧的局部约束环境。WT Gly6 不具有这一侧链。上述是单个模型输入初始帧的距离核查，不是原始晶体坐标上的精细相互作用测定；原文已经论述的盐桥、氢键和能量机制应引用原文，不能以本距离检查代替原文实验。

未替换 P7 与 P9 的空间位置对解释模型读数尤其有用。P7 主链 O 接近 TCR β 链 His 和 Asn 的主链 N：WT 的距离分别为 2.956 和 2.998 Å，G12D 为 3.109 和 3.032 Å；P9 主链 N 与 TCR β 链 Gly 的主链 O 距离分别为 2.897 与 2.875 Å。两状态均保留这些既有接触位置，模型却读出了 P7、P9 的主链运动差异，因而可把“新增 D6–HLA 网络”与“已有 TCR 识别接触位点的动态环境变化”连在一起。这里的距离只说明近接触，不自动判定氢键；本分析没有量化这些接触在运动中的寿命或形成频率。输入链 D 为 TCR α，E 为 TCR β；输入 β 链 His101/Asn102/Gly99 对应论文中的 His100β/Asn101β/Gly98β，写论文时必须使用文献编号并说明来源，不能混用。

文献事实由同轮独立文献核查代理核实，原始来源为 Poole 等 Nature Communications 2022, 13:5333，DOI 10.1038/s41467-022-32811-1（PMC9464187）。文献把 D6 埋入 HLA、与 Arg114/Gln70 组成的相互作用网络，以及诱导契合、静电与焓熵补偿联系起来；SPR 测得 JDIa41b1 对 WT 的 K_D 为 3.00×10⁻⁶ M，对 G12D 为（7.43±0.18）×10⁻¹⁰ M。论文中的具体 MD、SPR 温度系列和热力学描述应以本轮 `kras_affinity_literature` 的逐项来源核查结果为准。本模型的贡献是把高亲和复合物所对应的受约束主链状态定位到 D6 及邻近、未突变的识别位点，从单张复合物输入结构给出这一动态分布；不是计算上述 K_D 比值或结合自由能。

可供正文采用的模型段落为：“模型给出的两条绝对 RMSF 曲线揭示了集中在肽中央及 C 端的响应。替换位 G6/D6 的预测 RMSF 从 1.080 降至 0.718 Å，未替换的邻位 G7 从 1.246 降至 0.904 Å；A5、V8、G9 和 K10 也呈下降，而 N 端 V1–V3 基本重合（图4b）。G7 与 G9 位于原研究确定的 TCR 主链接触位置，因此这一响应把突变引入的局部约束延伸到了既有识别界面的动态环境。结合原文报道的 D6–HLA 相互作用网络，模型预测为高亲和 G12D 复合物中肽主链受约束的状态提供了逐位点支持，并展示了识别氨基酸未改变位置动态响应的能力。”具体接触机制与实验段应由主代理结合完整文献审计整合，避免把此段单独当成亲和力的因果证明。

需要守住的科学边界是：这些是已结合复合物中的主链 RMSF，不是未结合肽的预组织程度；更低的已结合态波动不必然提高结合亲和力，也不能直接换算结合熵。原研究中 G12D 结合存在更大的有利焓贡献，同时付出更大的熵代价，不能写成“更低 RMSF 减少结合熵损失所以高亲和”。这些边界用于内部审稿约束即可，正文无需堆叠防御性说明。正文应正面说明模型观察到的区域响应、它与文献已证实网络的空间关系，以及这种读数对解释该案例提供的新增信息。
