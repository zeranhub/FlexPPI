# Figure 4 statistics and reproducibility

The figure shows the residue-resolved backbone-motion profile predicted for the WT and G12D peptide in the same TCR–HLA context. Panel b displays absolute model RMSF values in Å, allowing the reader to locate the predicted motion change at the altered peptide residue and at the unchanged neighboring residues. Binding constants in panel a are source-literature measurements. Affinity is not numerically predicted by this model.

Panel a retains the three existing PyMOL-rendered molecular images byte for byte: 7ow5_binding.png, 7ow6_binding.png and peptide_superposition.png. The images were generated from the actual model-input PDB structures. MHC Cα positions 1–180 define the rigid transform without outlier rejection or peptide refitting. Both complexes retain the existing camera, size and shared crop; the peptide superposition retains its original crop. The all-10 peptide Cα RMSD remains 0.605462877 Å, displayed as 0.61 Å. The WT and G12D binding constants remain 3 μM and 743 pM from ref. [28], doi:10.1038/s41467-022-32811-1. Annotation fonts were increased from 7–8 pt to 9 pt; the peptide superposition title padding was increased to avoid a collision after font enlargement. Molecular data, alignment and displayed quantitative values were not changed.

Panel b contains all 10 residue positions for each of two complexes, 20 plotted values in total. The sequences are VVVGAGGVGK (WT) and VVVGADGVGK (G12D), and peptide position 6 is G versus D. Source columns rmsf_full_a and rmsf_full_b are plotted without recalibration, normalization, smoothing, averaging across residues, or offsetting of the x positions. A connected line indicates sequential positions, and markers distinguish the states in addition to their colors: WT orange open circles, G12D purple squares. These 10 positions are not independent biological replicates. No interval, error bar, significance test, correlation or MD similarity score appears in the figure. The source file contains additional archived MD and alternative-model columns, but those columns are not plotted. The 60 existing per-trajectory MD peptide values are preserved in source_archive/source_all10_peptide_six_MD_replicas.csv.

The plotted model is family_full_no_ITrace, checkpoint SHA256 ff2974406d5d1ee07e6dc7118e43e57c0acc9849cc8feba7f5290476fca15ec5. It is the same joint RMSF/Hχ model used for the existing KRAS case, and only its RMSF head is used here. All ITrace entries were excluded in this model's family fold, with training based on ATLAS/DynaRepo. One pre-existing checkpoint is used; no model is retrained, no inference is rerun, no new MD is performed, and no alternate checkpoint is chosen to improve this example. Old strict and intrachain model columns remain archived only.

All plotted values are traced to source_archive/source_all10_peptide_model_and_MD_changes.csv. The self-contained figure-only table source_plotted_model_RMSF.csv provides the 20 visible values by position and amino-acid identity. data_audit.json records the source hash, exact values, model identity, preserved image hashes and crop parameters, axis limits, state colors and all visible text. source_manifest.json binds every file copied from the former figure directory by SHA256. The full former plot, figures, molecular-render script, editable PyMOL session, six-trajectory table and statistical documentation are preserved in source_archive without modification.

Reproduce by executing plot.py with the bundled Codex Python. The script imports the existing project plot_runtime directory, then reads only the locally archived source table and molecular images. The production LineTrend/plot_trend.py script and its rendered companion were inspected. The existing KRAS script was copied first and adapted: its panel-a composition and molecular assets were retained, while its previous paired difference/MD panel was replaced by the two absolute prediction profiles requested by the user. The canonical typography, palette and export blocks remain verbatim at the script top. The existing WT #CF8C27 and G12D #762A83 colors are reused across panels.

The master dimensions are exactly 183 × 130 mm. PNG export is 450 dpi, 3242 × 2303 pixels. PDF/SVG preserve vector axes, lines, markers and editable text; only the three existing molecular renderings are raster image layers. New annotation and axis fonts are 9 pt at master size, or 8.2446 pt at 167.64 mm Word insertion width. Superscripts/subscripts use the standard math-font reduction. A 0–1.4 Å linear y-axis includes all original predictions.
