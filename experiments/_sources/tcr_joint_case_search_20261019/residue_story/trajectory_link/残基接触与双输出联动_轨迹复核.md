# MEL5：HLA Q72 与 TCR βGly54 的残基接触复核

结论是可以将双输出故事具体到这两个均未发生氨基酸替换的残基：亲和成熟后的TCR重新组织β链第二识别环与HLA的接触，HLA Q72侧链与该环主链之间相应接触的占据率提高，模型同时预测Q72侧链取向状态更集中以及对侧βGly54主链波动减小。现有六条轨迹显示Q72 Hχ的三重复均值降低、对侧Gly54波动降低，支持这一空间相邻、共同约束的解释；Q72 Hχ的单个重复在两状态之间仍有重叠。没有计算连续接触驻留寿命，因此占据率提高不能表述为单次接触更持久。数据不支持将Hχ本身当作驱动力，写成“Q72的Hχ下降直接导致Gly54 RMSF下降”；更准确的机制起点是受体序列和局部接触几何改变，两种动态读数描述相同局部网络的互补响应。

编号必须使用校正序列对齐：天然MEL5输入3HG1的β50–54为SVGIG，工程受体4JFF输入的对应β51–55为WGPFG。本文共同/原研究编号的βGly54，在工程模型输入中是链E第55位；HLA Q72在两者中始终是链A第72位。与Q72另一端接触的βIle53/Phe53，分别对应天然输入E53与工程输入E54。原始输入、预测NPZ和轨迹拓扑的全蛋白序列、链次序及对应索引已逐一核对。应在最终图中统一采用原研究/共同编号，图源记录保留两套编号，不能把工程输入55误称为新增残基或不同位点。

模型给出Q72 Hχ由1.79245降至1.37505 nats，下降0.41740 nats；对侧未替换βGly54的RMSF由1.11786降至0.74686 Å，下降0.37100 Å。Gly本身没有可定义的侧链χ角，所以其模型Hχ读数应忽略；这里的侧链输出来自有三个χ角的Q72，主链输出来自Gly54，正好构成不同残基、不同动态自由度的联系。模型预测不是以下MD统计的拟合产物，本轮也未作任何新训练或推理。

全部已有0–200 ns轨迹（天然与工程状态各三个独立重复，1,001–1,003帧/重复）显示，Q72侧链五个重原子到βGly54所有重原子的最短距离≤4.0 Å的帧比例，天然为0.0%、45.7%、27.7%，工程为93.2%、99.0%、99.9%；若改用4.5 Å阈值，三重复平均由37.2%升至97.4%。Q72 NE2与Gly54主链O的特定氢键几何占据，即供体–受体≤3.5 Å且供体–氢–受体角≥150°，天然为0.0%、2.8%、0.0%，工程为38.7%、45.2%、44.5%。这是按明确几何标准识别的接触，不能直接解释为能量或结合自由能。Q72的另一端OE1与βIle53/Phe53主链N–HN的相同几何占据，在天然三个重复中为0.0%、0.2%、0.0%，工程为75.9%、84.3%、85.8%。两处氢键几何在同一帧同时满足的比例，天然三个重复均为0%，工程为33.2%、39.5%、38.8%，三重复平均37.1%。因此，工程受体中经常出现由Q72酰胺两端连接相邻β53/β54主链的双端构型，但不应称其为全程保持的桥联。这个具体接触关系比“某处熵低、另一处波动低”的远距离关联更有结构依据。

按原标签完全相同的逐链Cα对齐复算，βGly54的MD RMSF天然三个重复为1.570、1.582、2.526 Å，工程为1.029、1.000、1.204 Å，工程所有重复均低于天然所有重复。Q72 Hχ天然为2.159、1.080、1.811 nats，工程为1.515、1.035、1.105 nats，三重复均值1.684→1.219 nats。Q72存在明显重复差异，不能声称任意一个工程重复的Hχ均低于任意一个天然重复。全部这些逐重复结果在原标签数值精度内精确复现，未更改时间窗、丢弃重复或挑选位点后的最佳轨迹。

Q72的工程状态主要分布在联合χ状态9与15，这两个粗分箱状态合计占工程三个重复的75.5%、88.1%、85.8%，在各自状态内Q72 NE2–Gly54 O距离≤4 Å的比例约87.3%–95.5%。主要状态9占每条工程轨迹的50.3%、65.4%、59.3%，其中同帧双端氢键几何占41.8%、46.3%、48.3%；次要状态15占25.1%、22.7%、26.5%，其中同帧双端氢键几何占20.2%、21.9%、23.4%。天然状态主要占联合状态21（44.3%、58.9%、53.0%），该状态的相同NE2–O距离接触比例为0%、32.0%、0%，同帧双端氢键几何均为0%。这个结果支持侧链取向重排为面向Gly主链的接触构型。固定120°粗分箱在−180°/180°边界两侧会把物理上相近的角度分开，因此不能把联合状态9与15直接解释成两个完全不同的功能构象，也不必在主文展示人为状态编号。

将每条轨迹划为十个不重叠20 ns窗口后，窗口内Q72 Hχ与Gly54 RMSF的Spearman描述性相关，天然三个重复为−0.527、0.236、0.382，工程为−0.055、−0.164、0.091，方向不稳定。Q72 Hχ与Q72–Gly54接触占据的窗口相关，工程三个重复为−0.701、−0.522、−0.522，但工程接触接近饱和，窗口帧数有限，天然第一重复又没有该接触，不能由此推断方向性因果或报告显著性。不能把60个窗口或6,000余帧当成独立实验样本。主文适合使用结构接触及全时间窗的重复支持，完整保存短窗口结果即可。

可用于后续正文的叙述骨架是：“亲和成熟重新组织了βCDR2与HLA的局部接触。模型预测HLA Q72的侧链联合状态熵下降，同时预测与其相邻的未替换βGly54主链波动下降。结构中Q72的酰胺基连接β53与β54主链，已有独立轨迹中这些接触的占据率提高，与模型定位的侧链约束和对侧骨架稳定相一致。两类输出从侧链取向与主链运动两个层面共同描绘了亲和成熟后的界面重排。”结合亲和力变化及原研究实验的结论需要由负责文献核实的分析补全；本分析本身没有计算亲和力、结合熵或焓。
