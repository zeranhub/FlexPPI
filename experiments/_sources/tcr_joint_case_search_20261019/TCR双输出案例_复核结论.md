# TCR–pMHC中RMSF与Hχ联合论证的候选

2026年10月19日。推荐优先推进MEL5与其已发表衍生受体α24β17的比较（3HG1/4JFF）。它比当前KRAS G12D更适合展示两类输出的互补作用：模型预测TCR识别环的主链约束增强，同时在氨基酸序列未改变的pMHC界面预测侧链取向状态重排，并已有“保留pMHC原坐标、移去TCR输入”的对照，能进一步说明侧链预测如何依赖结合伙伴。若研究问题要求两项读数共同解释同一条肽、同一个位置，则此前SB27/SB47对照更直接；JM22 F5L可作后备，PIK3CA目前较弱。

这次直接读取现有Full第0折联合模型的NPZ，逐项核对MEL5、PIK3CA、SB27/SB47和JM22源表中的预测值，共检查5,654个均值，并将现有MD重算均值与NPZ评价目标对应。MEL5只使用修正后的全链配准，旧错位的CDR3结果没有使用。该模型训练使用ATLAS和DynaRepo的2,430条记录，ITrace训练记录为0。没有新增模型训练、前向预测或MD；所有候选、完整区域和源文件哈希保存在data_audit。此前343个不同结构对的筛查已包括在候选背景中，这次是围绕联合叙述的复核，不把新筛出的局部案例当作额外独立的泛化评测。

## MEL5能够讲出的故事

原研究以SPR测得MEL5及α24β17对相同MART-1肽–HLA-A2的解离常数为18 μM和0.6 nM。晶体结构显示总体识别姿态和肽构象相近，增加的接触主要位于TCR–MHC一侧：MHC接触数从56增至97，肽接触数从39增至42，βCDR2的总接触数由6增至38。这给模型提供的应用问题是：在总体结构相似的条件下，能否辨认增强的接触环境对应的骨架约束和侧链状态变化。原研究做的是SPR、晶体学和温度依赖SPR热力学分析，没有报告本模型定义的RMSF或Hχ；当前动态预测提供额外的局部信息。[原研究](https://pmc.ncbi.nlm.nih.gov/articles/PMC3696650/)。

模型预测全部5个βCDR2位置的RMSF降低，区域均值0.896→0.636 Å；全部13个βCDR3位置也降低，均值0.801→0.648 Å。βCDR3内9个氨基酸未替换位置的均值为0.828→0.634 Å，说明读数变化覆盖邻近未改类型的骨架。两条CDR3合计22位的变化排序与现有MD相关为0.779，全部六条识别环45位为0.440，不能将β环的现象扩写为每条α/β环均准确。具体主张应是模型定位到主要的β链骨架约束响应。

在另一侧序列未变的pMHC界面，全部23个可比较Hχ位置包括17个预测下降、6个预测上升，适合讨论侧链状态的重排。其变化排序与现有MD为0.755，变化MAE为0.202 nats；去掉输入中的TCR后，在同23个位置为0.057和0.271 nats。两次输入对照保留每个状态自己的pMHC坐标，因此可支持“完整模型使用TCR上下文预测对侧界面侧链状态”，不能把它解释为真实解离过程或单独证明结合亲和力的因果关系。完整区域中增加和下降的位置均保留，不能只展示下降的几个侧链。

更具体的空间联系来自βCDR2邻近的MHC Q72。模型Hχ由1.792降至1.375 nats；相同MHC位点主链RMSF由0.557降至0.473 Å。保留原pMHC坐标而移去TCR输入时，Q72的Hχ变化由−0.417变为+0.104 nats。本轮检查模型使用的已有初始结构，在两状态βCDR2与HLA的全部≤4 Å重原子近接触并集中，涉及K68、Q72、R75和V76；Q72近接触原子对数4→15、最近距离3.53→2.94 Å。这里的几何结果来自既有MD初始输入，不能冒充原文晶体接触精确计数，也不等同接触寿命。它把“受体环主链波动降低”和“对侧Q72侧链取向状态更集中”定位在同一片接触区域，适合提出接触重排对应局部动态约束的解释。

上述接触集合需要完整报告。K68、R75、V76的模型Hχ变化分别为−0.247、−0.046和+0.076 nats，现有MD均值变化分别为−0.235、+0.350和+0.021；Q72现有MD均值变化为−0.465 nats且三重复范围重合。R75的方向不同不能删掉，接触增加也没有要求所有邻近Hχ同步下降。E58和R65还可作为另一处结构解释：原文明确点名E58参与新增接触，模型Hχ从2.629降至2.551；R65从1.794降至1.412。K68数值较好，但不能单独包装成新增侧链锁定的中心。

因此，推荐的核心叙述是：“在MEL5亲和成熟对照中，模型将TCR识别环的主链约束与未改变pMHC界面的侧链状态重排联系起来；两类输出分别描述受体骨架和对侧取向选择对增强接触环境的响应，侧链响应还依赖输入中的TCR信息。”原研究的SPR和结构分析提供结合差异及接触变化的实验依据，ITrace重复MD用作动态趋势的补充观察。原研究有利的结合熵主要联系溶剂重排，不能用已结合态Hχ下降替代该热力学解释。

## 其他候选为何排序在后

|候选|能联合论证的内容|当前判断|
|---|---|---|
|MEL5 / α24β17|受体β识别环RMSF与同序列pMHC界面Hχ，另有移去TCR输入对照|首选；适合展示同一识别界面的互补动态信息|
|SB27 / SB47|同一13肽中央骨架与Q7侧链对不同TCR识别方式的响应|同肽联合解释最直接；全肽Hχ排序不如Q7局部结果强|
|JM22 WT / F5L|同TCR识别单点抗原替换后，未替换肽位置的主链与侧链响应|关系清楚，但同AA侧链预测变化偏小，联合机制增量有限|
|PIK3CA 21LT2-2 / 0606T1-2|同序列pMHC界面33个RMSF和26个Hχ位置|双读数可比较，主链整体响应弱于优先候选，跨TCR位置不可硬配|

SB27/SB47的原研究通过晶体结构和肽替换后的细胞反应实验，说明前者重点识别肽中央突起，后者的识别更偏向N端。模型对Q7的RMSF为0.850→1.449 Å，Hχ为1.726→2.825 nats；移去TCR后Q7的Hχ分别约2.680和2.663，差异接近消失。因此可以讲“识别位置改变，使同一肽中央的主链运动与侧链取向限制共同变化”。全13肽RMSF变化排序为0.945、11个有效Hχ位置为0.321，Q9等位置没有同样好的预测。它更适合解释识别足迹差异，不必强行以亲和力高低作为主线。[原研究](https://pmc.ncbi.nlm.nih.gov/articles/PMC3668706/)。

JM22的原研究SPR报告WT为1.79±0.5 μM、F5L大于200 μM，结合态晶体显示诱导契合形成近似原肽的构象。模型在排除F5L本位后的8个主链、6个有效侧链位置仍有正向排序相关，但F7的模型Hχ仅0.792→0.830 nats、V6仅0.748→0.775，变化不足以形成像MEL5或SB27那样清楚的侧链故事。原文游离态到结合态的结构重排不能直接当作两种已结合复合物Hχ差异的测量。[原研究](https://pmc.ncbi.nlm.nih.gov/articles/PMC4843436/)。

## 图文推进建议

若将MEL5推进为论文案例，可采用结构定位、两状态识别环RMSF、完整pMHC界面Hχ及TCR输入对照的组合。RMSF展示全部六条识别环并突出β环所在区域，Hχ展示完整23个界面有效位置及无χ角位置标识，用空间连线将βCDR2与Q72所在界面联系；原研究结合实验数值及接触事实标明来源。主图以模型绝对读数与结构位置为主体，重复MD只提供简洁的动态佐证。这会将两类输出组织为同一个识别问题的连续证据。

目前没有改动论文或替换KRAS。此次候选数据和解释已归档，足以据此选择后续正式实例；不需要为判断候选先重新训练或启动新的MD。
