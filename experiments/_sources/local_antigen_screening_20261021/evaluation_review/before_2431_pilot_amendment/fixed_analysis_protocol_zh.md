# 本地抗原改造回顾实验：预先固定的评估协议

本实验要检验一个具体问题：在同一TCR和同一HLA中，模型从一组抗原变体结构给出的RMSF与Hχ，能否帮助排列真实SPR结合强弱，并在序列和静态结构信息之外增加预测信息。实验单位是一个独立抗原候选，而不是一个残基、一个模型构象或一次模板计算。公开数据当前包含1G4–NY-ESO-1的14种肽和A6–Tax的16种肽。1G4以这套变体实验共同采用的9V肽SLLMWITQV为参照，主结构固定为2BNQ；天然9C肽SLLMWITQC在这里作为9位变体，不能把9V悄悄称为天然野生型。A6以Tax肽LLFGYPVYV和1AO7为参照。按这两个参照，每个体系各有13种单点替换，分属六个替换位置；A6另有两种双点替换。所有序列与分组已写入candidate_splits.json，后续仅能依据文献来源、测量定义或结构完整性排除候选，不能依据预测好坏改变集合。由于体系的文献背景和此前个别案例已知，本实验是回顾检验，不能表述为盲法发现新抗原。

实验标签只使用直接测量单体TCR与pMHC结合的SPR平衡解离常数，不将pMHC稳定性、2D亲和力、细胞激活浓度或杀伤读数混入。统一先从原始单位重新换算pKD：把KD换为mol/L，再取负的常用对数，数值越大表示结合越强；如果原单位是μM，需要先乘以10⁻⁶。主标签是同一study、相同方案及温度下候选pKD减参照肽pKD。源数据能确认study和37°C测量，但不能逐肽确认同批运行编号，因此文中只说同研究和方案归一化，不能声称每个候选均有同批配对测量。Pettmann的原文已给出拟合选择规则：constrained KD超过20 μM时使用constrained结果，否则使用Bmax自由拟合结果；此原研究报告规则固定为主标签，全部constrained与全部自由拟合分别作为完整敏感性分析。两种拟合或多篇研究不能增加独立抗原数。1G4的两个研究均有9V参照，各自先计算study内差值，再在确认为可比较的条件下对同一候选差值取中位数，并保留逐研究结果。不得照搬下载脚本，把不同研究的同序列pKD直接混合平均。任何“未结合”“大于检测限”等记录保留为区间，不把边界当作准确KD回归；无同研究参照的记录不强行构造主标签。

模型固定为联合训练的Full family fold0、seed7、第40轮，权重SHA为ff2974406d5d1ee07e6dc7118e43e57c0acc9849cc8feba7f5290476fca15ec5，不更新基础权重。其代码实际只读取氨基酸身份及每个残基N、CA、C、O的主链坐标，侧链朝向本身不会进入网络。因此，在固定骨架上替换侧链得到的预测变化，检验的是模型结合局部结构环境对氨基酸替换的响应，不能据此说模型重新采样出突变后的构象。所有候选和参照必须经过相同、与亲和力无关的确定性准备。每个体系统一使用一个主模板，禁止为不同候选按实验亲和力、预测效果或“最接近的已知强结合结构”挑模板。2BNR，以及A6的1QSE、1QSF，只作为提前列明、对所有候选完整运行的模板敏感性；每个模板都先减去自己的参照预测，不能把不同模板的绝对值差异当作抗原替换效应。多个构象和多个模板始终汇总到一个候选，不构成独立实验重复。

两项主动态特征都放在化学身份未改变的周围蛋白上，以免把替换位置本身侧链角数不同误认为环境识别。具体做法是在参照结构上一次性选定距离肽任一重原子8 Å以内的HLA重链及TCR两条链残基，不包括β2微球蛋白；这份位置清单随后对全部候选保持不变。R特征是这些位置的模型RMSF变化的平均值；H特征是其中有侧链χ角的位置的模型Hχ变化平均值，Gly和Ala不参与Hχ平均。主链变化描述这些位置活动幅度的改变，侧链变化描述它们取向选择的丰富程度改变，两者都不是结合自由能，也不能预先规定“越低就一定越好”。替换位置的Hχ、整条肽的曲线、分开的HLA/TCR曲线和所有逐残基结果可以归档展示，但不能在看到SPR成绩后另选最好的残基、半径、方向或汇总方式代替这两个主特征。

比较对象提前固定为零变化、序列、静态结构、序列加静态结构，以及在同一基线上分别加R、加H、同时加R与H。序列信息包括相对参照的替换数，以及BLOSUM62中“保留原氨基酸的分数减去实际替换分数”的总和。静态信息包括TCR与pMHC结合界面的埋藏表面积变化，以及肽与TCR之间4.5 Å内残基接触对数量变化；具体SASA参数和计数方式写在JSON中，所有结构使用相同算法。固定骨架的CA接触若完全不变，不能冒充有力的静态基线。若侧链准备或SASA无法可靠完成，只能把结果标成序列加动态读数的受限可行性分析，不能据此声称超越了静态结构方法。所有特征一次性确定，禁止按成绩筛特征或把实验标签作为结构准备输入。

主检验在各体系内部留出一个替换位置：例如P5的所有替换一起留出，其余位置用于拟合，随后只预测未见的P5候选；循环六个位置，每个候选得到一次真正留出的预测。参照肽只用于计算差值，不作为一个容易预测的零值训练样本。使用固定惩罚强度1.0的线性ridge，基础模型不训练；这里的小回归只把少数固定特征换成亲和力变化。每一折只用训练候选计算各特征的均方根尺度，保持差值零点，不居中、无截距，不用测试候选重算尺度，也不搜索惩罚参数。拟合目标是平均平方误差加1.0乘各系数平方之和，具体线性求解形式已给出。A6两种双点替换单列：在全部合格单点替换拟合后预测，作为组合变体检查，不混入主成绩或称为新位置外推。另做1G4训练后预测A6、A6训练后预测1G4的两个方向，全部规则不变；只有两个、且共享HLA-A2的体系，不能把这两次迁移包装成跨TCR普遍泛化的估计。

主成绩是每个体系各自的候选级留出预测平均绝对误差，单位为pKD差值，同时报告与所有变化均为零的比较。模型增量用“序列加静态基线误差减联合模型误差”表示，并同时列出加R和加H的结果：联合模型好于基线，只能说明整体动态信息可能有用；只有联合模型又好于各单项，才支持两项提供互补信息。两体系的方向和改善幅度必须分别给出，不能只汇报成功的体系或迁移方向。排序相关、全部可比较候选对的顺序一致比例、前三名重合以及完整候选排序可作为辅助，但不能替代幅度误差。这里不根据结果另定强弱结合阈值来制造ACC或AUROC，也不按成百上千个残基、候选间配对或结构构象计算虚假的显著性。公开测量差异、各位置留出误差和所有个体误差均保留；两个体系的小面板不能支撑总体泛化置信区间。若原始测量核对后任一体系少于8个合格单点变体或不足3个位置组，停止训练式排名主张，改为如实报告可行性和描述性结果。

本地训练重叠审查及原始模板审查已经完成，最终候选结构仍需在推理前核对实际读入序列、链身份、主链完整性、固定环境位置及权重字节SHA。新增或剔除标签、修复结构以及更改规则都需要记录版本与原因；不能在看过受影响的模型结果后无痕改动。一个正向结果能够支持在这两个已知TCR/HLA环境中使用FlexPPI读数辅助候选排序，不能直接证明设计出新抗原、增强细胞功能、没有交叉反应、计算了结合自由能，或证明了一个残基的Hχ改变导致另一个残基RMSF改变。
