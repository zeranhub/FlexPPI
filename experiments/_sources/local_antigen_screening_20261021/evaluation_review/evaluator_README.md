# 固定评价脚本

evaluate_screening.py只读取已经生成的特征与已冻结的SPR标签，不加载神经网络，也不更新基础权重。主模式为full，强制使用序列加静态结构基线；只有在技术准备阶段确定静态特征不可用时，才明确指定restricted。后者仅检验相对序列的动态增量，所有输出都会标记不能提出静态增量主张。输出目录必须为空，避免覆盖此前结果。

在D:/Anaconda/envs/pvb_cpu/python.exe环境运行evaluate_screening.py，指定--features为ROOT/feature_extraction/candidate_features.csv、--output为一个新的结果目录。特征CSV按76个生物候选×模板组合完整提供，每行含candidate_id、panel_id、template_pdb、sequence_n_mutations、BLOSUM62_deficit、delta_TCR_pMHC_BSA_A2、delta_peptide_TCR_contact_residue_pairs_4p5A、R、H、template_is_primary、preparation_qc_pass、dynamic_qc_pass、static_eligible；推荐同时保留n_U_RMSF、n_U_Hchi和feature_region_id。candidate_id必须是与SPR标签完全一致的生物候选编号，模板前缀另放input_id。每行checkpoint_sha256须等于协议中的历史2431模型SHA；也可通过--feature-manifest提供顶层checkpoint_sha256。执行脚本还会检查实际本地权重文件字节SHA。

程序固定完成三种SPR拟合版本、五个全部预设模板的体系内位置留出检验、两个主模板之间的双向跨体系检验，以及A6两种双替换的附加检验。主结果使用reported_hybrid、2BNQ与1AO7。各位置的同位替换一起留出，参照肽与双替换永不进入拟合；尺度只从训练候选计算。没有超参搜索、特征挑选、模板挑选或结果驱动阈值。两study敏感性使用同一候选留出预测，分别对各study原始差值打分，不再选择一个study特供模型。

输出包括每个候选的留出预测及完整排名、全部技术与标签排除记录、每折训练候选和系数/尺度、候选级及位置级误差、两动态读数的增量分解、逐study误差、两体系宏平均与完整执行审计。候选跨模板/模型/标签版本产生多行，是重复分析记录，不是新增独立实验。排序相关遇到不足三个候选或常数排名时留空；并列排名使用平均名次，预测并列的候选对记半分，前三名在截断点并列时按生物编号稳定排序并明确标记。所有规则在新候选结果前实现。

--self-test仅运行合成数值和冻结划分检查。test_evaluator_synthetic_integration.py另外用明确标记的临时合成标签及特征验证完整读写、三标签版本、全部模板、各检验分支、full/restricted模式和逐study输出，不读取真实SPR数值或候选预测；其记录为evaluator_selftest_audit.json。合成文件在测试后清除，不混入正式结果。固定骨架输入的独立审查为fixed_backbone_inputs_independent_audit.json；这份审查已核76份输入，但侧链完整性与最终固定环境U仍需在补齐重原子后独立复核。
