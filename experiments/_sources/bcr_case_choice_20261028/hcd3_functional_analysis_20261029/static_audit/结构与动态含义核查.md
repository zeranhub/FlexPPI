# 6A77完整H-CDR3：结构环境与动态读数的实际核查

本次分析使用冻结A00LZ输入，共519个残基、3933个重原子；抗原为A链Robo1 Ig5，轻链为B，重链为C。H-CDR3作者95–109号全部15位纳入；同时计算全部6个CDR、可变区框架和未编号常数区。重原子最短距离统一检查4.0、4.5、5.0 Å；链内非局部接触排除序列相邻2位。SASA按Bio.PDB Shrake–Rupley、1.4 Å探针、240球面点计算，H-CDR3进一步在960点下复查。所有结果仅为一个结合态的结构与当前MD参考之间的对应，不包含亲和力、突变因果或结合前后差值。

## 当前最具体的问题

可以检验的问题是：同一抗体识别环中，骨架位置波动与侧链取向多样性是否对应到不同的局部环境？起始结构给出了一个可核查的例子：R101的主链O接近轻链Y49的OH（3.214 Å），而R101侧链到轻链的最近重原子距离为5.701 Å、到抗原为8.668 Å，侧链自身仍高度暴露。960点计算的R101侧链SASA为189.13 Å²。模型对R101骨架RMSF从链内对照1.640 Å修正为完整模型1.149 Å，接近MD参考1.123 Å；与此同时，完整模型的Hχ为3.431 nats，接近MD的3.419 nats，保留了侧链的较高状态多样性。这里可以展示两种读数如何帮助区分一个残基的主链和侧链，但还需结合逐帧接触占据验证起始主链近邻是否在轨迹中维持。单凭静态距离不能写成稳定氢键或功能因果。

R96提供同类型参照：R96侧链SASA仅16.20 Å²（960点），在4.5 Å内有10个非局部重链残基邻居，R96的NH1与D108的OD2起始距离2.654 Å。R96与R101的MD Hχ分别为1.801与3.419 nats，完整模型为1.969与3.431 nats。相同化学类型在紧密链内环境和溶剂暴露环境中具有不同侧链多样性，这一对应超出了单纯按氨基酸种类给值。不过链内模型也恢复了该差异：1.782与3.358 nats；因此这组参照解释读数含义，不能独立证明跨链模型的新增优势。

## 不能写成的机制

抗原接触不等于低骨架RMSF。4.0和4.5 Å下，H-CDR3直接接触抗原的恰好是E97、P103、Y104、Y105；5.0 Å还包括P102。4.5 Å下接触与非接触位置的MD平均RMSF为0.820与0.852 Å，差异很小；5.0 Å下变为0.874与0.829 Å，方向反转。因此不能用低RMSF直接标记抗原接触位点，更不能据此标记亲和力热点。不同类型侧链混在一起的接触/非接触Hχ均值也不能作为环境效应的独立证据。

Y104和Y105确实同时接近抗原与轻链。960点时其复合物残基SASA约14.35与6.00 Å²，删除抗原后分别增加54.94与22.34 Å²；其侧链到抗原最近距离为3.550与3.415 Å，到轻链为3.808与3.679 Å。当前MD Hχ为0.547与0.653 nats，完整模型为0.815与0.937，链内对照为1.692与1.434；完整模型的绝对误差确实更小。但不能挑Y104就说完整模型恢复了所有同型侧链环境差异：H3内第三个Tyr109的MD Hχ为0.908，完整模型0.876，链内模型1.271。MD三个Tyr的顺序为104<105<109，完整模型为104<109<105；两个界面Tyr的完整模型均值0.87588几乎等于Tyr109的0.87624。完整模型没有恢复全部Tyr环境对比。

P102/P103的Hχ合法参考为零，来自Pro侧链几何及当前标签定义。不能将该零值当作抗原结合导致的刚化或亲和力机制。P103在起始结构有较多抗原邻接和较大埋藏面积，骨架RMSF仍约1.002 Å，因此这个结合态也不是整环均匀低波动的例子。

## 可支持的叙事层次

本例支持对结合态抗体识别环进行有位置区分的动态描述：同一H-CDR3内，残基处于链内堆积、轻链邻接、抗原邻接或溶剂暴露环境，主链RMSF与侧链Hχ为这些结构位置补充了不同动态信息。若逐帧分析确认R101主链接触维持而侧链仍多态，可以进一步把“局部主链近邻与侧链状态多样性共存”作为具体问题。现有静态分析本身不证明这会提高亲和力或维持特异性，也不证明结合前后的整体刚化。它的机制新意仍有限，应与现有CaM/泛素/TCR案例比较后决定是否占主文篇幅。
