# MEL5–α24β17 跨界面几何核查

本轮仅分析先前已用于模型推理的两份全原子起始结构（3HG1、4JFF对应的模拟准备后模型输入），没有生成新构象，也没有把静态起始结构距离写成MD平均距离。全部距离单位为Å。共同编号按MEL5序列对齐：HLA Q72在两个输入中均为A72；WT βIle53为E53、成熟βPhe53为E54；WT βGly54为E54、成熟βGly54为E55。成熟受体有N端编号+1，正式图中应使用共同编号。

**固定原子对的几何变化很清楚，足够支持一个同视角双态局部图。** Q72 OE1–β53主链N从5.8488缩短至2.9429；Q72 NE2–β54主链O从10.5844缩短至3.1196。这里的两个WT距离与先前“最近重原子距离”不同，因为本轮前后固定相同原子定义；不能把不同定义混在同一个箭头上。对应的残基任意重原子最近距离分别是Q72–β53：5.4551→2.9429，Q72–β54：8.2650→3.1196；Cα间距分别是9.9948→7.0651和12.3123→8.9190。这三个定义都指向相同的局部靠近，但正式图以固定原子对最直观且可解释。

Q72周围不是所有接触都共同增强：βVal51→Gly51的最近重原子距离由3.5278略缩至3.2516；βGly52→Pro52由4.4700缩至3.3253；Q72–βGln55却由3.9433增至4.7565。因此应称为**接触伙伴与局部几何的重排**，不应概括成整个界面无选择地压紧。βGly54保留了残基身份，几何靠近与其RMSF预测降低（1.1179→0.7469 Å）共同把模型响应定位到未替换的接触片区；Q72也保留身份，其Hχ为1.7924→1.3750 nats。β53发生Ile→Phe变化，模型RMSF为0.9688→0.7548 Å，其身份变化本身会影响物理性质，不能把它当作严格同残基对照。

建议正式图上并列两个同视角局部图，Q72统一teal，WT βCDR2橙色、成熟βCDR2紫色，用元素色区分氮和氧；固定两个原子端点以虚线标5.85/10.58和2.94/3.12 Å，直接将Q72的Hχ和βGly54的RMSF小字注到对应残基附近。βGly52→Pro52与βIle53→Phe53可标作受体改造背景。结构图中的几何靠近是起始输入本身的信息，模型额外提供的是同一局部片区的侧链状态集中与主链波动降低；把二者放在同一个图中可建立可追踪的空间解释，但不能由此证明Q72 Hχ降低导致Gly54 RMSF降低，更不能用两条距离定量解释全部亲和力增益。

双态渲染将WT用HLA A链1–180位全部180个Cα对齐至成熟结构，拟合RMSD=0.5237 Å；使用同一个正交相机、同一个中心、缩放和1800×1500画布。背景已改为细tube，避免短截断螺旋和β箭头掩盖接触端点。屏幕映射用4个独立彩色探针定标，再以第5个独立探针验证，误差0.027像素；坐标原点在原始PNG左上角，可供正式图矢量标注。两个原图不得独立缩放；若裁切空白，请使用相同裁切框，再在排版中使用相同尺寸。

计算表在本目录，渲染图、PSE和投影JSON在相邻structure目录。`fixed_atom_contact_distances.csv`用于正式图距离；`Q72_to_all_aligned_TCR_residues.csv`是完整邻居审计；`all_interface_pairs_within6A_in_either_structure.csv`是整个pMHC–TCR界面在任一结构6 Å内的全部对齐残基对，并附模型读数；`local_Q72_betaCDR2_neighbor_network.csv`保留HLA65–76与β48–56的局部网络。任意重原子最近距离表中的最近原子可能前后改变，使用时必须保留定义。
