# KIX MD 输入与既有预测的差异

主方案遵照 Peiffer 2022 S1 的 MD 构建方法：2AGH 模型1，KIX B586–672（87残基），cMyb A291–315（25残基），MLL C839–857（19残基）。四状态为 apo、myb、mll、both。旧案例脚本使用 MLL840–858，序列 DDGNILPSDIMDFVLKNTP；本轮为839–857，序列 SDDGNILPSDIMDFVLKNT。不是相同序列，应针对新MD输入重新预测，不能直接套用旧图中的数值。

2AGH作者存档MLL D841缺少CG、OD1、OD2，末端裁至T857后还缺OXT；这四个原子必须在MD构建阶段补齐。D841与参考UniProt的Cys存在SEQADV冲突，本输入保留实际存档的Asp，不执行野生型回退。本脚本没有补原子或改变任何保留原子的坐标，manifest逐原子追溯源行号、原子序号、坐标和哈希。

源PDB五个His（B592、594、602、605、651）均仅含HD1环氢，支持把HID作为明确的初始假设，但不能证明原作者MD就用此质子化状态。源结构N端含H1/H2/H3，完整C端含OXT。拟采用带电未封端链端；S1未明确端基，不能把正文合成实验肽的乙酰化/酰胺化直接当成MD事实。PDB的pH5.5是NMR样本条件，不是S1确认的MD pH。

必须由后续构建流程记录实际HIS模板、总电荷、重建原子与端基，并检查蛋白主链完整、没有意外链间共价键，再进入能量最小化及短测试。该输入产物本身不能直接视为MD就绪。
