# 增量筛选试验：未查看结果的协议复核

本复核由协议审查代理完成，读取了两份冻结协议、公开数据提取记录、候选表的表头及前两行、模型训练重叠审计；未打开evaluation目录内任何结果、未读取Full或intrachain预测/排名/比较指标。此前只读检查了2026-10-21既有SPR标签说明，知道旧面板仅有两个受体、30候选，不能凭该面板训练通用筛选器。当前改用公开All-designs.xlsx的279个设计候选，在三个体系内分别保留完整93个设计，包括功能阴性，排除的仅是WT及未刺激对照。这一扩大数据的选择有合理性，但仍是已发表设计集合上的回顾性探索，不是前瞻性筛选证明。

当前冻结的B0/B1/B2比较可以执行。B0使用官方ERGO-II两个版本及NetTCR分数；B1增加作者已公布的结构预测/呈递描述；B2再增加八个提前指定的受体区域动态特征。统一的L2逻辑回归、固定C=1、仅训练集标准化和缺失处理、整体系留出及对照的做法，能避免最直接的结果导向调参。序列组成与逐位置氨基酸对照是必要追加：FlexPPI输出是给定残基身份和几何的确定性变换，若只与缺少明确序列信息的基线比较，改进可能只是重新编码肽序列。只有基础B2改善而加入序列控制后改善消失，不能归因于动态信息。相同分类器和C不等于严格相同参数容量，新增八个系数依然提高了自由度，因此同维度打乱特征对照应完整报告，不能只报告优于零增益。

本试验的主要限制是固定骨架。所有设计肽被放入每个体系相同的参考复合物主链，仅改变肽身份并去除被替换残基的侧链原子。这是公平、可复现的模型敏感性输入，但没有让突变肽和TCR重新找结合姿态或平衡构象，也不判断该复合物能否实际形成。它测试的是“相同假设姿态下，由残基身份导致的受体动态表征变化是否有排序用途”，而不是完整突变动态或真实结合自由能。两个模板只是相关结构的敏感性分析，不能当作两次独立生物学验证。受体区域取均值会进一步压缩局部模式；即使本轮没有增益，也只说明这套输入和八个冻结特征尚未显示用途，不能通过事后寻找新区域把同一试验改写为成功。

B1并非从本轮固定骨架输入直接计算的一套纯静态几何特征。它包含作者的TCRdock PAE、AF3界面PAE及NetMHCpan指示量，来自不同建模流程或序列模型；应准确称为“公开结构预测与呈递特征基线”。因此B2相对B1的增益可证明此公开候选集合上的增量预测用途，但不能单独证明FlexPPI捕获的真实柔性产生了因果作用，也不能证明排除了所有静态结构信息。原设计集合经过HERMES生成和作者筛选，PAE等特征可能已被筛选条件截断；该集合不能代表任意抗原搜索空间。不能使用作者设计方法名称、预判阳性标签、真实功能强度作为输入，也不能删除原设计中的阴性或难建模候选来提高命中率。

标签是作者给出的resp/resp_el4功能阳性，不是直接结合阳性、KD或免疫原性全流程的结论。不同体系的细胞/呈递背景和阳性判定条件可能不同，必须保留源字段与原判定，不能为了平衡类别重新择阈值。前三个体系的数据提取记录分别有NYESO 30/93、EBV 13/93、MAGE 19/93阳性，基础阳性率已有明显差异；应逐体系报告top10命中数、平均精度及排序相关，宏平均作为摘要，不以把三次预测简单合并得到的高总体指标替代。连续响应只适合各体系内的次分析，不宜直接混合不同测量标度。与作者原模型相比是否更好是另外的问题，当前主要检验B2与B1的增量。

整体系留出的训练/测试隔离是这批数据最重要的保护：每次用两个TCR体系训练，完整预测第三套93候选，不把同一设计肽、模板或时间重复拆进两侧。但真正的独立受体体系仍只有三个，不是279次独立跨体系验证。需要展示三套完整差值，不能用279候选的普通独立样本检验制造很小的p值，也不能用模板数、200个打乱种子、残基数扩大生物学样本量。即使三个体系均改善，也宜称初步的跨体系增量信号；若只在一个体系改善，需明确不稳定。Hamming距离不超过2的成组留出可补充已知受体内的新肽任务，但若连通分量巨大、训练折缺少某类或组数不足，应原样报告不能估计，不能退回随机逐行划分求一个漂亮分数。只有MEL5少数代表点时不应拟合任何下游模型，它们仅适合独立案例解释。

重叠审计覆盖当前完整3063记录/4973组成链及实际fold0的2430训练记录，公开审计中没有发现达到该替代比对阈值的训练命中，这比沿用旧不完整FASTA可靠。但它仍是Biopython局部/全局比对的透明替代，不是原MMseqs搜索的逐项复现；短肽的近同源关系也未由长链规则完整认证。已发布基线训练集覆盖、预训练结构信息、TCR或近邻表位的潜在接触都需分别披露。整体系下游留出不自动排除基础模型曾见过该体系，故不宜称严格zero-shot或从未接触的全新抗原验证。

建议按冻结方案完成推断及比较，不再改区域、阈值、分类器或选最佳模板；报告原始基础分数与校准后B0，避免只比一个不合适的基线。最有说服力的正结果是：B2相对B1在逐体系top10和平均精度上方向一致，加入序列控制仍保留，主/备模板不反转，且高于同维度打乱特征通常产生的变化。即便如此，主张也限定为“FlexPPI表征辅助的功能候选重排序”。若这些条件未满足，应报告本次未显示稳定增量，保留动态预测/分析用途，不把功能或亲和力筛选写成既有能力。本复核只规定解释边界，未查看结果，也不预判最终会成功或失败。
