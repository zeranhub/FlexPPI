# ITrace fixed-coordinate partner-context ablation

This directory contains the complete source data for the full-complex versus
partner-deleted-subcomplex experiment.  The external-clean cohort contains
244 PDB complexes after excluding exact training PDB
overlap 3KXF.  Retained pMHC or TCR coordinates are unchanged; the maximum
verified atom-coordinate difference is
0.0e+00 A.

The independent statistical unit is the PDB complex.  Intervals use
2000 complex-level bootstrap resamples.  This is a
model-context ablation and must not be interpreted as an apo/holo response.
