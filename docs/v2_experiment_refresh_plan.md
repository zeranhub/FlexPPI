# FlexPPI v2 实验重跑与图表更新方案

日期：2026-09-06。状态：盘点及折外预测入口准备中；图组方案待用户确认，尚未启动全量重跑或正式制图。本方案不覆盖旧模型、旧预测、旧论文图表。

## 目标与范围

目标是用已经完成的五折模型重做适用的旧实验，补齐模型横评，并使每个图表数值都能追溯到测试样本、留出折、模型权重、输入结构、标签和统计代码。结果如实反映提升或退步，不预设 FlexPPI 获胜，也不因新结果不好而重选测试样本或案例窗口。

主线使用现成五折的全部 3068 个样本：ATLAS 1929、DynaRepo 895、ITrace 244。Hχ 只有 DynaRepo 与 ITrace 的 1139 个样本有标签，不能把 ATLAS 记为 Hχ 测试样本。ThermoPCD 待准备的 36 个体系不加入这轮主评测。旧 ATLAS 191＋DynaRepo 85 样本保留为版本对比子集，不以这个较小子集代替全量横评。

“重跑实验”指重新计算模型依赖的预测、统计和图表，不必重新训练模型或重新模拟 MD。现有结构、MD 真值、链角色、CDR 区域、界面注释和重复轨迹可靠性分析可以在核对身份、版本及标签口径后复用。

## 五折协议

对每个样本，唯一合法的测试模型是其 `fold_k_test.jsonl` 对应的 `fold_k/epoch_040.pt`。将 5 折测试预测拼接得到全体的折外预测（OOF）。不能用 5 个模型平均测试同一个池内样本，因为其他 4 个模型训练过它；不能选测试分数最高的折或 checkpoint。

上下文消融中的完整复合物、删除伙伴、孤立链必须沿用原完整体系的同一留出折。删除链或改变 sample_id 不会使它变成一个可由任意模型测试的新样本。静态外部案例只有在确认不属于训练池的同一体系后，才能另行使用五模型集成；这种结果须明确标为外部案例，不能混入 OOF 主榜。没有 MD 真值的案例只能展示预测或结构代理关联。

训练集与测试集的样本 ID 不重合，不等于严格的未见家族测试。ITrace 已进入新版训练池，图表使用“ITrace OOF / 跨体系测试”标签，不沿用旧 `zero-shot` 或 `external_clean` 结论。其他预训练模型的训练集重叠能核对多少就报告多少，未知部分明确记为未知。

## 统计口径

保留两个明确分开的口径。第一，主横评延续旧表：单链蛋白直接计算指标；复合物先逐链计算，再在复合物内让各链等权，最后让各复合物等权，避免大链淹没短肽。第二，另提供与服务器评估报告一致的完整体系指标。两种数值分别标注，不能互相替换。

横评的所有方法必须在相同样本和相同有效残基上比较。至少保留 Spearman、Pearson、z-MAE、AUROC、AP、P@K（K 为有效残基的最高柔性 20%，取整与并列处理固定并记录）。有真实 Å 单位的预测再报告绝对 MAE/RMSE；相对柔性分数或 B 因子不能直接当成 Å。z-MAE 的标准化规则沿用被审计的旧横评定义，不能为不同模型采用不同的有利规则。

五折结果画出每折的实际点，并在表中报告均值与折间标准差（明确 ddof）；折间波动不是五次独立训练重复，也不是 95% 置信区间。另对共同体系上的模型差值做配对汇总，置信区间以生物体系为重采样单位，必要时补充按划分簇的敏感性分析；不把同一体系的残基当成独立样本。多个模型/区域的显著性检验需说明多重比较校正。

Hχ 的氨基酸类别均值只从各折训练标签估计，应用到对应测试折。删除旧硬编码 0.882 先验水平线；补充相同氨基酸类型内排序与扣除类别均值后的排序。预测和真值同时减去同一个先验不改变 MAE/RMSE，不能把这两个误差称为独立的类别校正证据。

## 拟制作图组

各图科学问题预先固定，图中结论由重跑结果决定。采用定量面板网格，案例曲线/热图采用左右配对布局；正文图按双栏 183 mm 设计，统一字体、配色及单位，交付 PDF、可编辑 SVG、300 dpi PNG 和逐图源数据及统计说明。

| 图组 | 面板及形式 | 回答的问题 | 数据范围 |
|---|---|---|---|
| 1. 主横评 | RMSF 三类体系总表；ITrace/区域另表；五折点图 | 新版与其他方法在相同残基上各有什么优势和不足？ | 全量 OOF；旧样本桥接榜单另列 |
| 2. 预测与 MD 真值 | Hχ、RMSF 两个密度图，附系统级指标；全域分层放补充 | 预测是否准确，是否偏低估高柔性区域？ | 首先复现 ITrace 244，再分层展示其他有标签队列 |
| 3. 固定残基案例 | 两个旧案例各一条多模型曲线和一个热图，共 4 面板 | 同一位置上新版与旧版、基线的局部误差如何变化？ | A000K A 209–298；1h16_A 666–755，不重选优势窗口 |

## 基线与运行顺序

用户提及的实际本地目录为 `E:\Project\FlexPPI\baselines` 与 `E:\Project\protein_flexibility_models`。先保留旧主榜的 FastProtFlex、BackFlip-seq、BackFlip-structure、ProDy-ANM、ProDy-GNM、RMSF-net-PDB，再评估新发现的 PLANET-MD 两种版本的可用性与输入映射。完整的路径、依赖和检查结果另记 `docs/v2_baseline_inventory.md`。

旧基线有 ATLAS 191、DynaRepo 85、ITrace 244 的逐残基缓存。只有在模型/权重、结构输入、链切分、预处理和残基对应关系经过核对后才可复用预测，并在统一真值上重新统计；全量新增样本必须补跑。新基线或失败方法先做单样本验证，再进入批量，不把“代码/权重已经下载”当成“能直接运行”。当前机器无 CUDA，部分基线所需 Docker daemon 未运行，不擅自把失败模型移出表，失败状态和覆盖数量都保留。AlphaFlow 已下载的六体系 ensemble 只做单独小样本补充，不混入全量排名；需要 cryo-EM 密度或只预测 B 因子的模型另列输入/目标不同的补充分析。

执行顺序为：核对清单与哈希 → 新版全量 OOF 残基缓存 → ITrace 上下文缓存 → 校验及补跑基线 → 共同残基统计和五折汇总 → 图 1–7 → 适用的其他旧实验图。当前第一步新增独立 OOF 导出器，绕开尚未同步完整的旧评价入口，不修改训练逻辑。

## 缓存、失败与复现

新预测默认写入 `artifacts/evaluation_v2/`，新图表及统计说明写入 `output/flexppi_v2_figures/`。旧 `artifacts/evaluation/`、`output/flexppi_performance_figures/` 和 `paper/figures/` 原稿不覆盖。用户确认最终图后，才考虑替换论文引用或生成新版论文图目录。

每个缓存记录 sample_id、fold、模型/输入/标签哈希、完整链及作者残基编号、输入条件、两项预测和方差、标签和有效性掩码。缺文件、结构标签长度不等、重复样本、留出折冲突、缺预测、不兼容缓存均显式报错。小样本 smoke 输出明确标为不完整，不可冒充完整评测。断点续跑只复用身份核验一致的已完成缓存。

ITrace 6VMA 的旧 CSV 与既存 NPZ 有 98 个 RMSF 标签差异；本轮统一采用冻结 v2 NPZ，旧预测也在同一标签上重算，并将这个历史差异留在审计中。不得用旧 CSV 真值计算部分图、用 NPZ 真值计算另一部分图后合并声称同口径。

## 适用性边界与扩展

旧脚本固定需要 SASA 和 response head 的实验，不能原样搬到新版。新版仅 RMSF/Hχ，SASA 面板归档而不补零；固定坐标删链实验只能说明模型对输入上下文的敏感性，不能直接等同真实结合前后的 MD 动力学变化。旧 apo/holo response-head 实验保留为历史材料；若重做状态差值，需另立不同于直接响应头的评价协议。

现有 CDR1/2/3、framework、CDR3β 失败分析、肽位置/接触距离、界面定位、6UON/2PTT/7L1D/7RRG 结构案例可复用统一新缓存逐项更新；只有纯数据诊断无需因换模型而重算。完整映射另见 `docs/v2_experiment_figure_inventory.md`。
